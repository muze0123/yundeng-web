# 商城产品需求文档

> 产品：YunLogin PC 端  
> 模块：商城  
> 事实来源：`YunLogin图片文字索引.tsv` 中“商城”截图索引  
> 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`  
> 价格说明：本文与原型中的价格、折扣和活动日期均为截图快照或 Mock 演示值，不代表当前真实报价

## 1. 产品目标

商城为用户提供代理资源、团队套餐和购物车的统一购买入口。页面需要在高密度配置下持续展示订单试算结果、优惠和风险提示，使用户在支付前能够明确核对商品、地区、时长、数量、续费周期和最终金额。

## 2. 用户与权限

- 团队管理员：购买代理、升级或续费套餐、管理购物车并提交支付。
- 采购成员：配置商品并加入购物车；支付是否可用由团队权限控制。
- 普通成员：查看商品，不能使用团队资金支付。
- 系统：提供商品库存、动态价格、优惠券、套餐抵扣和订单试算。

## 3. 页面结构

复用统一 App Shell。商城业务区采用顶部 Tab：代理、套餐、购物车。代理和套餐采用“左侧配置 + 右侧粘性订单摘要”，购物车采用数据表格 + 结算摘要。

页面必须展示合规提示：产品不提供翻墙服务；代理资源由第三方提供；用户应遵守适用法律法规，不得用于违法犯罪或侵害他人权益。海外代理仅允许在合规网络环境或完成实名认证后使用。

#### 3.1.3 页面模块布局

| 模块 | 位置与层级 | 内部组成 | 尺寸与间距 | 滚动、固定与联动 |
|---|---|---|---|---|
| 合规提示条 | 主内容区顶部 | 合规说明、实名认证/帮助入口 | 高度随文案，底部间距 12px | 随主内容滚动；不可被订单摘要遮挡 |
| 一级页签 | 提示条下方 | 代理、套餐、购物车 | 高 44px | 切换页签保留未提交配置和购物车选择 |
| 商品配置区 | 代理/套餐页签左侧 | 商品字段、联动选项、优惠券、支付方式 | 左侧最小宽度 640px | 字段变化触发试算；加载时禁用提交 |
| 订单摘要 | 代理/套餐页签右侧 | 商品明细、小计、优惠、实付、主操作 | 宽 320-360px | sticky 于主内容顶部下方；随试算结果更新 |
| 购物车列表 | 购物车页签左侧 | 商品表格、数量、删除、批量选择 | 表格最小宽度 900px | 仅表格横向滚动；选中变化更新结算摘要 |
| 支付确认弹窗 | 全局层 | 订单明细、金额、支付方式、安全提示 | Modal 宽 520px | 原型不创建真实订单；确认后仅展示模拟反馈 |

#### 3.1.4 响应式与溢出规则

- ≥1280px 使用左配置右摘要双栏布局，摘要 sticky。
- 768-1279px 双栏改为上配置下摘要，摘要不遮挡主操作。
- ＜768px 页签横向滚动；配置项单列；订单摘要固定在提交区上方或折叠为结算栏。

## 4. 代理购买

### 4.1 配置字段

| 字段 | 规则 |
|---|---|
| 代理类型 | 电商社媒主推、全球家庭住宅-静态、云平台-静态、快速检索购买 |
| 代理地区 | 国家与城市联动；提供热门地区快捷入口和搜索 |
| 代理号段 | 随机分配或自定义购买；自定义只展示支持号段选择的商品 |
| 代理资源 | 按地区、类型与号段筛选；展示资源名和月价 |
| 购买数量 | 正整数，受库存和单次限购约束 |
| 购买时长 | 1、3、6、12 个月；折扣由试算接口返回 |
| 优惠券 | 仅展示满足门槛、商品和有效期的优惠券 |
| 自动续费 | 开启后选择 1、3 或 12 个月周期；需提示账户余额 |
| 支付方式 | 支付宝、微信、账号云币；云币余额不足时提供充值入口 |

### 4.2 联动

- 切换类型或地区后重新加载资源并清空不兼容的号段、资源与优惠券。
- 价格、时长、数量、优惠券变化后调用订单试算，更新订单金额、折扣、优惠券抵扣和实付金额。
- 无库存资源禁用并显示原因。
- “加入购物车”保存当前配置；相同 SKU、地区、号段、时长和续费配置可合并数量。
- “立即购买”先校验购买须知，再进入支付确认；原型止于确认前。

## 5. 套餐购买

| 字段 | 规则 |
|---|---|
| 环境数 | 10、50、100、200、500、1000、2000、5000 等档位 |
| 额外成员数 | 非负整数，按成员单价计费 |
| 购买时长 | 30、90、180、360 天；长周期折扣由接口返回 |
| 优惠券 | 满足套餐范围与门槛后可用 |
| 自动续费 | 可选；明确续费周期与扣款账户 |
| 支付方式 | 支付宝、微信、账号云币 |

订单摘要同时展示现套餐、新套餐、环境数、成员数、到期时间、新套餐金额、现套餐抵扣、优惠券抵扣和总价。升级按剩余价值抵扣；减配不退款，提交前必须显著提示并再次确认。

## 6. 购物车

- 展示商品类型、配置摘要、单价、数量、优惠、金额和操作。
- 支持单选、全选、数量调整和删除。
- 商品失效、库存不足或价格变化时阻止结算并要求刷新试算。
- 结算仅统计已选有效商品；购物车角标实时更新。
- 批量结算前逐项校验购买须知、实名/网络要求和支付权限。

## 7. 订单摘要与金额规则

订单摘要在配置区滚动时保持粘性。金额统一保留两位小数并使用等宽字体：

`实际应付 = 订单金额 - 折扣优惠 - 优惠券抵扣 - 套餐剩余价值抵扣`

前端仅展示试算结果，不自行决定最终价格。提交订单必须携带 `quote_id`、价格版本和幂等键；报价过期时重新试算并让用户确认变化。

## 8. 支付确认与安全边界

- 用户必须勾选《代理购买须知》或《套餐购买须知》后才能提交。
- 明确提示代理类数字商品一旦下单不能退换。
- 原型不调用真实支付、不创建真实订单，只展示确认弹窗。
- 支付密码、二维码、完整订单号和实名信息不得写入日志或埋点。
- 支付过程中禁止重复提交，关闭页面后可在费用管理查询真实订单状态。

## 9. 状态与异常

- 商品加载失败：保留已选配置并提供重试。
- 地区无资源：展示空态并推荐其他城市。
- 库存变化：标记资源不可用，重新选择。
- 优惠券失效：移除抵扣并解释原因。
- 试算失败：禁止下单，保留配置。
- 报价过期：刷新金额并要求再次确认。
- 购物车部分商品失效：有效商品仍可选，但不可静默删除失效商品。
- 云币不足：禁止云币支付并提供充值入口。

## 10. 接口建议

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/store/proxy-products` | 查询代理商品与库存 |
| GET | `/api/store/regions` | 查询国家、城市与热门地区 |
| GET | `/api/store/plans` | 查询套餐档位和计价规则 |
| POST | `/api/store/quotes` | 统一订单试算 |
| GET | `/api/store/coupons` | 查询可用优惠券 |
| GET/POST/PATCH/DELETE | `/api/store/cart` | 管理购物车 |
| POST | `/api/store/orders` | 创建订单，携带幂等键 |
| POST | `/api/store/orders/{id}/payment-intents` | 创建支付意图 |

## 11. 埋点

- `store_tab_view`：proxy / plan / cart。
- `store_product_select`：product_type、region、duration_bucket；禁止记录代理地址。
- `store_quote_result`：success、amount_bucket、coupon_used。
- `store_add_cart`：product_type、quantity_bucket、success。
- `store_checkout_click`：source、item_count、payment_method。
- `store_checkout_blocked`：reason。

## 12. 验收标准

1. 代理、套餐、购物车三个 Tab 可切换，状态互不污染。
2. 代理类型、地区、资源、数量、时长、优惠券和续费配置真实联动订单摘要。
3. 套餐环境数、成员数和时长变化后金额与到期信息同步更新。
4. 加入购物车可新增/合并商品，角标与金额实时更新。
5. 购物车支持选择、全选、数量调整、删除和结算统计。
6. 未同意购买须知不可立即购买或结算。
7. 支付只到确认弹窗前，不创建真实订单。
8. 所有价格均标记为演示试算，最终金额以后端为准。
9. 交互标注默认隐藏且连续编号，弹窗无标注穿透。
10. 单文件可预览，无本地资源依赖，JavaScript 无语法错误。
