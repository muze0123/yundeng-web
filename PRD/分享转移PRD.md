## 1. 需求概述

### 1.1 问题陈述

浏览器环境包含账号、代理、指纹、Cookie 与缓存等高价值资产。团队既需要将环境临时共享给外部协作团队，也需要在组织调整或项目交接时永久转移环境或平台代理。若分享与转移混为同一动作，用户容易误判资产归属、有效期、数据范围和撤回能力；若缺少统一台账，则难以回答“分享给谁、何时到期、谁执行、能否撤回、资产是否已永久离开原团队”。

### 1.2 解决方案

提供“发起入口 + 三类台账”的协作资产工作台：

- 环境管理负责选择资产并发起分享或环境转移；代理管理负责发起平台代理转移；
- 分享管理展示当前与历史分享，支持组合查询、详情和取消仍在进行的分享；
- 环境转移与平台代理转移仅展示不可逆所有权变更记录，用于追踪目标团队、操作人与时间；
- 发起动作在提交前明确展示数据范围、目标团队、缓存/代理风险和不可逆影响；
- 服务端以权限校验、幂等、审计日志和一致性校验保证跨团队资产流转可追溯。

### 1.3 用户、角色与任务

| 角色 | 任务（JTBD） | 权限边界 |
|---|---|---|
| 团队创始人 | 安全分享或永久转移团队资产，追踪全部流转记录 | 可查看全部记录、创建/取消分享、转移环境与平台代理 |
| 团队管理员 | 在授权范围内协作交接资产 | 需分别具备查看、分享、取消分享和转移权限 |
| 环境管理员 | 分享或转移被授权环境 | 不可操作未授权环境或团队级平台代理 |
| 普通成员 | 查看与使用接收到的资产 | 本页面默认不提供转移或再次分享能力，最终规则见待确认项 |
| 审计/只读成员 | 查询分享和转移记录 | 不显示或禁用创建、取消与转移入口 |

### 1.4 一句话目标与成功指标

让用户在不混淆“临时分享”和“永久转移”的前提下，完成跨团队资产流转并全程可查、可控、可审计。

| 指标 | 目标 |
|---|---|
| 分享/转移提交成功率 | ≥ 99%（排除权限与业务校验失败） |
| 重复提交导致的重复记录 | 0 |
| 操作记录可追溯率 | 100% |
| 取消分享后新会话阻断生效 | ≤ 5 秒（V1 决策） |
| 列表查询 P95 | ≤ 2 秒 |
| 敏感信息进入日志或埋点 | 0 |

### 1.5 范围与非目标

**P0 范围：**

- 三个业务页签及各自查询、空态、分页；
- 分享中/已关闭状态筛选、记录多选与取消分享；
- 从环境管理发起创建分享、环境转移；
- 从代理管理发起平台代理转移；
- 权限校验、二次确认、审计与幂等；
- 详情查看及批量部分失败反馈。

**P1 范围：**

- 附件预览、操作记录导出、目标团队名称回显；
- 分享即将到期提醒与到期任务监控。

**非目标：**

- 在分享转移页创建或编辑环境、代理、团队；
- 真实云端快照上传、附件上传服务和跨团队消息中心；
- 将分享等同于授权，或允许接收方默认再次分享；
- 恢复已完成的永久转移；
- 未经产品确认自动删除接收方已落地的缓存副本。

### 1.6 边界条件汇总

| 场景 | 规则 |
|---|---|
| 无查询结果 | 保留筛选条件，展示“暂无符合条件的记录”与重置入口 |
| 分享列表未选记录 | “取消分享”禁用 |
| 已关闭记录 | 不可选择，不出现取消操作；可查看详情 |
| 目标团队等于当前团队 | 阻止提交并定位到团队 ID 字段 |
| 重复目标团队 ID | 前端去重并提示；服务端以去重后的集合提交 |
| 缓存数据未存在云端快照 | 阻止勾选缓存提交，提供查看教程入口 |
| 正在运行的环境 | V1 决策：允许分享但禁止转移，提示先关闭环境 |
| 代理不具备转移条件 | 本地网络、已过期、未授权或被其他环境共用时明确提示并按规则阻止/部分提交 |
| 批量部分失败 | 成功项落库，失败项保留选择并展示逐项原因 |
| 并发状态变化 | 以服务端最新状态为准，不覆盖；提示刷新或展示最终状态 |

## 2. 信息架构、入口与用户流程

### 2.1 入口与路由

| 入口 | 目标 | 说明 |
|---|---|---|
| 左侧导航“分享转移” | `Prototype/分享转移.html` | 默认打开“分享管理”，状态为“分享中” |
| 环境管理 > 批量操作 > 分享 | 创建分享 Modal | 带入所选环境 ID |
| 环境管理 > 批量操作 > 转移 | 环境转移 Modal | 带入所选环境 ID |
| 代理管理 > 平台代理 > 转移 | 平台代理转移 Modal | 带入所选平台代理 ID |
| 三类台账 Tab | 当前页面内部切换 | 切换时保留各 Tab 独立查询草稿，页码回到 1 |

### 2.2 页面关系

```text
环境管理 ──分享──> 创建分享 ──成功──> 分享转移 / 分享管理
环境管理 ──转移──> 环境转移 ──成功──> 分享转移 / 环境转移
代理管理 ──转移──> 平台代理转移 ──成功──> 分享转移 / 平台代理转移
分享管理 ──详情──> 分享详情抽屉
分享管理 ──取消分享──> 二次确认 ──成功──> 状态更新为已关闭
```

### 2.3 核心流程

#### 2.3.1 创建环境分享

1. 用户在环境管理选择 1 个或多个环境并点击“分享”。
2. 系统展示已选数量和脱敏摘要；用户选择是否包含缓存数据。
3. 若包含缓存，系统检查每个环境的云端快照；不满足项阻止提交并列出原因。
4. 用户设置分享时长（天）、逐行输入目标团队 ID、填写备注并可选择图片附件。
5. 前端完成团队 ID、时长、备注与附件校验，展示预提交摘要。
6. 服务端再次校验资产权限、目标团队、重复分享与状态；通过后按“环境 × 目标团队”创建分享记录。
7. 成功后进入分享管理并高亮新记录；部分失败展示成功数、失败数与原因。

#### 2.3.2 取消分享

1. 用户在“分享管理 / 分享中”勾选记录。
2. 点击“取消分享”，Dialog 展示记录数量和影响说明。
3. 用户确认后提交幂等请求；成功记录改为“已关闭”，取消时间与操作人写入审计。
4. 已关闭、已到期或并发取消的记录不重复处理，返回最终状态。

#### 2.3.3 环境转移

1. 用户选择环境并打开转移 Modal。
2. 系统明确提示“转移后环境完全归目标团队，原团队不可查看”。
3. 用户选择转移内容：指纹环境、代理信息、账号信息、Cookie 信息、缓存数据；输入一个目标团队 ID。
4. 系统校验环境已关闭、目标团队有效、资产权限及代理/缓存可转移性。
5. 用户在确认 Dialog 二次确认；成功后更新环境归属并写入环境转移台账。

#### 2.3.4 平台代理转移

1. 用户选择一个或多个平台代理并输入目标团队 ID。
2. 系统检查代理状态、授权范围和关联环境。
3. 若代理同时绑定其他环境，明确列出将变为“IP 已转移”的关联环境；用户二次确认。
4. 成功后更新代理归属并写入平台代理转移台账；失败项保留在选择中。

## 4. 页面与交互规格

### 4.1 分享管理

#### 4.1.1 筛选与操作

| 项目 | 规格 |
|---|---|
| 状态 | 下拉选项依次为“全部、分享中、已关闭”；默认“分享中” |

| 环境备注 | 最多两行省略 |

#### 4.1.3 选择规则

- 表头全选只选中当前页“分享中”记录，不选已关闭记录；
- 支持跨页选择，批量栏显示总选择数；切换 Tab 清空选择，切换筛选保留仍在结果集中的选择；
- 单次取消上限 **V1 决策：100 条**；超过上限时阻止提交并提示缩小选择范围；
- 服务端对每条记录独立校验，批量请求允许部分成功。

### 4.2 环境转移

| 项目 | 规格 |
|---|---|
| 搜索 | 占位“搜索名称、IP、团队 ID”；匹配环境名称、脱敏 IP、目标团队名称/ID |
| 表格 | 序号/ID、名称、账号、IP、转移给团队、操作人、操作时间 |
| 操作 | 台账只读；点击名称或行内“详情”打开转移详情抽屉 |
| 空态 | “暂无环境转移记录”；提供前往环境管理入口 |

环境转移是所有权变更记录，不提供撤销、编辑或删除入口。

### 4.3 平台代理转移

| 项目 | 规格 |
|---|---|
| 搜索 | 占位“搜索代理名称、IP、团队 ID”；匹配代理名称、脱敏 IP、目标团队名称/ID |
| 表格 | 代理名称、IP、服务商、转移给团队、操作人、操作时间 |
| 操作 | 截图无操作列；**V1 原型决策**：点击代理名称打开详情抽屉，不新增可见操作列 |

### 4.4 创建分享 Modal

#### 4.4.1 字段

| 字段 | 类型 | 规则 |
|---|---|---|
| 已选择环境 | 多选列表 | 必填；至少 1 个；展示序号、名称、分组、运行状态和快照状态 |
| 缓存数据 | Checkbox | 可选；勾选后校验全部所选环境存在可用云端快照 |
| 分享时长 | 步进器/数字输入 | 必填；单位天；**V1 决策：1-365 天，默认 7 天** |
| 分享给团队 | 多行输入 | 必填；每行一个团队 ID；去空行、trim、去重；不可为当前团队 |
| 备注 | Textarea | 0-200 字，右下角实时计数 |
| 图片附件 | 文件选择/粘贴 | JPG/PNG；单图 ≤2MB；**V1 决策：最多 5 张**；仅展示本地预览，不上传真实服务 |

#### 4.4.2 提交规则

- “确定”前执行字段校验和资产权限预检；提交中按钮 loading 且禁止重复点击；
- 多环境、多团队按笛卡尔积生成记录，但请求使用一个批次 ID；
- 已存在相同环境、相同团队且时间区间重叠的“分享中”记录时，**V1 决策：阻止重复创建并列出冲突项**；
- 关闭 Modal 时若有输入，提示是否放弃；成功后关闭 Modal、清空草稿并切至分享管理第一页。

### 4.5 环境转移 Modal

| 字段/提示 | 规则 |
|---|---|

| 代理信息 | 本地网络、已过期、未授权代理不可转移；共用代理需列出影响环境 |

| 字段/提示 | 规则 |

| 关联环境提示 | 代理绑定其他环境时列出环境；转移后这些环境变为“IP 已转移”，需要重新绑定 |
| 最终确认 | 展示代理数量、目标团队和受影响环境数；危险确认按钮使用 danger 语义 |

### 4.7 详情抽屉

分享详情展示分享记录 ID、环境、分享内容、目标团队、有效期、状态、备注、附件、创建/取消信息与操作日志。转移详情展示源团队、目标团队、资产范围、关联影响、操作人、操作时间与结果。敏感账号、IP、团队 ID 始终脱敏，无权限时不提供复制完整值入口。

### 4.8 空态、加载与错误态

- 初始无记录：文案“暂无数据”“还没有相关记录”；可按当前 Tab 引导到环境管理或代理管理；
- 筛选无结果：文案“暂无符合条件的记录”，提供“重置筛选”；
- 加载：表格骨架，不清空上一轮筛选；
- 加载失败：保留筛选与选择，展示重试；
- 无权限：展示权限说明与联系管理员入口，不渲染敏感数据。

## 5. 权限、可见性与数据安全

### 5.1 权限矩阵

| 能力 | 创始人 | 有权限管理员 | 普通成员 | 只读审计 |
|---|---:|---:|---:|---:|

| 查看转移记录 | 全部 | 授权范围 | 否 | 授权范围 |
| 创建分享 | 是 | 需 `share:create` | 需显式授权 | 否 |

| 环境转移 | 是 | 需 `environment:transfer` | 否 | 否 |
| 平台代理转移 | 是 | 需 `platform_proxy:transfer` | 否 | 否 |
| 查看完整敏感值 | 需额外权限 | 需额外权限 | 否 | 否 |

### 5.2 安全要求

- 团队 ID、账号、IP 与附件名按权限脱敏；前端 Mock 也不得使用真实信息；
- 所有创建、取消和转移请求服务端重新鉴权，不信任前端按钮可见性；
- 附件只允许 JPG/PNG，校验 MIME、扩展名、大小并执行恶意内容扫描；
- 日志与埋点禁止记录账号密码、Cookie、2FA、完整团队 ID、完整 IP、附件内容和缓存数据；
- 转移接口要求近期二次认证或高风险确认的具体策略由安全评审确定；
- 取消分享只能阻断后续访问，不能承诺回收接收方已合法导出的数据，正式文案需避免过度承诺。

### 6.2 分享状态机

```text
创建中 creating ──成功──> 分享中 active ──到期任务──> 已到期 expired
       │                         └─用户取消──> 已取消 cancelled
       └─失败──> 不创建记录 / 批次返回失败明细
```

界面筛选“已关闭”聚合 `cancelled + expired`；详情中必须显示真实终态“已取消”或“已到期”，不能丢失原因。

### 6.3 业务规则

1. 分享不改变环境所有权；转移改变所有权且无页面撤销入口。
2. 同一环境可分享给多个团队；每个目标团队对应独立记录与状态。
3. 分享到期时间由服务端以创建成功时间计算，客户端时间不作为依据。
4. 只有 `active` 记录可取消；取消与到期竞争时，以服务端首个终态为准。
5. 转移成功后，原团队对资产的编辑/启动权限立即失效；列表缓存必须刷新。
6. 所有批量操作使用批次 ID 和每项结果，禁止以整批失败掩盖部分成功。
7. **V1 决策**：接收方默认不可再次分享或转移接收资产；待产品确认后再开放。
8. **待确认**：分享取消/到期后，接收方缓存副本的删除、保留或冻结策略。

### 6.4 并发、幂等与一致性

- 创建、取消、环境转移和代理转移均携带 `Idempotency-Key`；相同键重复请求返回同一业务结果；
- 取消分享携带记录 `version`，状态已变化时返回最终状态而非覆盖；
- 转移采用资产归属条件更新，确保同一资产只成功归属一个团队；
- 列表采用游标或稳定排序键 `operated_at DESC, id DESC`，避免翻页重复/遗漏；
- 到期任务与人工取消均写审计，前端通过刷新或事件通知收敛最终状态。

| 场景 | 响应与恢复 |

## 10. 非功能性与技术约束

- 性能：首屏数据渲染 P95 ≤2 秒；筛选前端反馈 ≤300ms；批量预检 P95 ≤3 秒；
- 可用性：提交按钮具备 loading 与防重复；失败保留筛选、选择与表单；
- 可访问性：Tab 使用正确角色与 `aria-selected`；复选框有可读标签；焦点陷阱、Esc 关闭与关闭后焦点恢复完整；不能只用颜色表达状态；
- 响应式：桌面 ≥1280px、平板 ≥768px 可用；表格只在自身容器横向滚动；
- 原型：单文件自包含，Tailwind CDN + Lucide CDN + 原生 JavaScript，无本地资源依赖；
- 标注：业务编号从 1 连续、默认隐藏；Modal/Drawer/Dialog 打开时使用作用域栈，页面标注不得穿透；
- 安全：输入输出转义、防 XSS/CSV 注入；客户端不持久化 Cookie、账号或附件内容。

## 13. 发布、灰度与回滚

- 以团队白名单灰度开启创建/取消和转移能力，先开放只读台账；
- 创建分享、取消分享、环境转移、平台代理转移使用独立功能开关；
- 回滚时仅关闭新操作入口，不删除历史台账与审计记录；
- 已进入处理中的转移请求继续查询最终结果，禁止前端因关闭开关而丢失状态；
- 发布前完成权限矩阵、幂等、部分失败、到期任务、附件安全和跨团队缓存策略评审。
