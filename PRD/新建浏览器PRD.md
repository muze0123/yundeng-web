# 新建浏览器产品需求文档

> 产品：YunLogin PC 端  
> 页面：新建浏览器  
> 事实基线：`YunLogin图片文字索引.tsv` 中“新建浏览器”第 365–372 行  
> 复用基线：`PRD/编辑浏览器PRD.md`、`Prototype/编辑浏览器.html`  
> 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`

## 1. 产品目标

新建浏览器用于创建一个或多个相互隔离的浏览器环境。用户可选择单个添加、批量添加、批量导入或一键迁移环境，并在创建前完成代理、账号、内核、操作系统、指纹、插件与偏好设置。页面需要降低首次配置成本，同时避免代理复用、指纹矛盾、Cookie 泄露和超套餐创建等风险。

## 2. 与编辑浏览器的关系

单个添加复用编辑浏览器的配置模型、控件、代理/账号弹窗、联动校验、指纹摘要和交互标注，但存在以下明确差异：

| 维度 | 新建浏览器 | 编辑浏览器 |
|---|---|---|
| 数据来源 | 系统推荐默认值与空业务数据 | 已保存环境的完整回填 |
| 接口语义 | `POST /api/browser-environments` | `PATCH /api/browser-environments/{id}` |
| 主操作 | 确定、确定并新建下一条 | 保存修改 |
| 成功结果 | 返回环境管理并定位新记录，或清空业务字段继续创建 | 返回环境管理并定位原记录 |
| 名称 | 默认“云登浏览器”，允许修改 | 回填已有名称 |
| 代理 | 默认本机网络，可换绑或自动分配 | 回填已有绑定 |
| 账号 | 默认未绑定，可新建或选择已有账号 | 回填已有绑定账号 |
| 离开保护 | 草稿发生变化后确认放弃 | 已保存值与草稿不同后确认放弃 |

## 3. 用户与权限

- 团队管理员：可使用全部创建模式、团队代理、账号和插件。
- 普通成员：仅可在授权分组与套餐额度内创建。
- 只读成员：不可进入创建页。
- 系统：提供套餐额度、网络检测、指纹生成、文件校验和迁移链接。

## 4. 页面骨架

页面复用统一 App Shell：左侧导航宽 220px/折叠 68px，顶部栏高 56px。业务区顶部为四个模式 Tab；单个添加和批量添加底部使用固定操作栏，批量导入与一键迁移在各自流程卡片内提供主操作。

### 4.1 四种模式

1. **单个添加**：创建一个完整配置环境。
2. **批量添加**：以公共配置一次创建多个环境，名称自动追加序号，代理按环境分配。
3. **批量导入**：下载模板并上传 xls/xlsx/csv 文件，完成本地校验后导入。
4. **一键迁移环境**：生成短期有效采集链接，在原浏览器中访问以迁移指纹与 Cookie。

切换模式时保留各模式内草稿；存在文件校验或提交中的任务时禁止切换。

#### 4.2.4 响应式与溢出规则

- ≥1280px 使用左表单右摘要双栏，底部操作栏固定。
- 768-1279px 摘要区下移到表单下方，仍在提交前展示。
- ＜768px 模式页签横向滚动；表单单列；底部操作栏按钮分两行时高度同步增加并预留安全留白。

## 5. 单个添加

### 5.1 环境信息

| 字段 | 默认值 | 规则 |
|---|---|---|
| 名称 | 云登浏览器 | 必填，trim 后 1–100 字；允许输入超过 100 字但显示错误并阻止提交 |
| 代理信息 | 本机网络 | 必填；支持本机网络、平台代理、自有代理、代理 API |
| 修改 IP 自动重新生成指纹项 | 关闭 | 代理确认变更后才触发 |
| IP 查询渠道 | IP2Location | 必填；切换后清除旧检测结果 |
| 账号平台 | 未绑定 | 可添加新账号或选择已有账号；敏感值脱敏 |

### 5.2 配置区

沿用编辑浏览器四个折叠区：

- 基础设置：浏览器内核、操作系统、UA、分组、标签、Cookie、打开网址、备注。
- 指纹设置：语言、时区、地理位置、屏幕、字体、ClientRects、WebRTC、Canvas、WebGL、硬件并发数、内存、设备名、MAC、硬件加速、蓝牙、DNT、电池与端口防护。
- 插件选择：插件分组与全局插件开关。
- 偏好设置：网页通知、图片/视频/声音、内存回收、缓存和 Cookie 清理、随机指纹。

右侧粘性摘要实时展示最终有效的内核、UA 与指纹值。随机生成新指纹必须成组更新内核/OS/UA/设备画像，不覆盖名称、代理与账号。

### 5.3 提交

- **确定**：全量校验后创建环境；成功返回环境管理并定位新记录。
- **确定并新建下一条**：创建成功后保留代理策略、分组、插件与偏好，重置名称、账号、Cookie、打开网址、备注并重新生成设备画像。
- **取消**：无修改直接返回环境管理；有修改弹出放弃确认。

## 6. 批量添加

| 模块 | 字段与规则 |
|---|---|
| 批量设置 | 创建环境数，最小 1，最大值受套餐剩余额度约束 |
| 代理配置 | 显示“已选择代理数 / 创建环境数”；支持自动分配与绑定代理；代理不足阻止提交 |
| 账号配置 | 选择平台与打开网址；不批量填写账号密码 |
| 基础/指纹/偏好 | 复用单个添加的公共配置；设备名、MAC 等每个环境独立生成 |
| 命名规则 | 手动输入名称时，最终名称为“输入名称 + 序号” |

当前截图基线显示套餐最多还可创建 1 个环境；原型使用可演示的 Mock 剩余额度 5，并明确额度来自接口而非硬编码业务规则。

## 7. 批量导入

### 7.1 步骤

1. 上传导入文件。
2. 数据本地校验。
3. 完成导入。

### 7.2 文件规则

- 支持 `.xls`、`.xlsx`、`.csv`；单文件不超过 10MB。
- 每次不超过 300 条。
- 提供“环境导入模板”下载入口。
- 上传后展示文件名、大小、有效行、错误行；错误报告可下载。
- 清空文件回到初始态；只有本地校验通过才允许下一步。

导入须知应提示：避免多个环境使用同一代理；敏感平台需保持 IP 时区、UA、Cookie 一致；敏感字段不得写入客户端日志。

## 8. 一键迁移环境

| 字段 | 规则 |
|---|---|
| 名称 | 必填，1–100 字；多个环境自动追加序号 |
| 选择平台 | 必填；用于匹配迁移源浏览器 |
| 设置数量 | 1–套餐剩余额度 |
| 批量生成链接 | 校验后请求一次性迁移链接 |

生成后展示链接、剩余有效时间与复制按钮。链接有效期 24 小时，倒计时归零后失效并允许重新生成；链接不进入埋点、Toast 或日志。迁移仅在用户于原浏览器访问链接并确认后采集指纹与 Cookie。

## 9. 状态与异常

- 套餐额度不足：禁用创建并提供升级套餐入口。
- 代理数量不足：批量提交前阻止并定位代理配置。
- 网络检测失败：保留代理草稿，允许重试。
- 文件格式/大小/行数错误：在上传区就地提示，不进入校验步骤。
- 文件部分错误：列出错误行数并允许下载报告；不导入有效行，避免半成功。
- 迁移链接过期：禁止复制旧链接，显示重新生成。
- 创建失败：保留表单与滚动位置，允许重试；不得重复创建。

## 10. 接口建议

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/browser-environments` | 单个创建 |
| POST | `/api/browser-environments/batch` | 批量创建 |
| POST | `/api/browser-environments/import/validate` | 导入文件校验 |
| POST | `/api/browser-environments/import` | 正式导入 |
| POST | `/api/browser-environments/migration-links` | 生成迁移链接 |
| GET | `/api/plans/environment-quota` | 查询套餐剩余额度 |

提交请求必须携带幂等键；密码、2FA、Cookie、代理提取链接与迁移链接不得进入日志或埋点。

## 11. 埋点

- `create_browser_mode_view`：mode。
- `create_browser_submit`：mode、environment_count、has_proxy、has_account。
- `create_browser_result`：mode、success、error_code、duration_bucket。
- `create_browser_import_validate`：file_type、row_bucket、error_count_bucket。
- `create_browser_migration_link`：count、success；禁止记录链接。
- `create_browser_cancel`：mode、dirty、confirm_shown。

## 12. 验收标准

1. 四个模式可切换且各自草稿不互相污染。
2. 单个添加完整复用编辑页的配置、代理、账号、指纹摘要与校验逻辑。
3. 名称 0/100/101 字、非法 MAC、非法端口均有明确校验并阻止提交。
4. “确定”和“确定并新建下一条”具有不同成功结果。
5. 批量添加数量受套餐额度限制，代理覆盖不足无法提交。
6. 批量导入仅接受指定格式、≤10MB、≤300 条，步骤状态真实变化。
7. 一键迁移链接可生成、复制、倒计时和过期重建。
8. 页面适配桌面与平板，主页面无横向溢出；长表单与弹窗独立滚动。
9. 标注默认隐藏，业务标注从 1 连续编号；弹窗打开时仅显示弹窗标注。
10. 单文件双击可预览，Tailwind CDN + Lucide + 原生 JavaScript，控制台无错误。
