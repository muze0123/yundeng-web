# 费用管理云币充值产品需求文档

> 产品：YunLogin PC 端
> 模块：费用管理 · 云币充值
> 页面文件：`Prototype/费用管理-云币充值.html`
> 设计约束：`AGENTS.md`、`design.md`
> 数据说明：原型中的余额、金额和支付结果均为 Mock 演示值，不代表真实资产或交易。

## 1. 产品目标与入口

在费用管理下提供云币余额查看和在线充值能力，团队成员可了解余额共享与自动续费规则。

- 导航名称：云币充值，位于费用管理下；余额明细为其后一个独立二级入口。
- 稳定路由：`index.html?page=billing-recharge`，路由 key 保持不变。
- 业务文件直开自动回到唯一 SystemFrame；旧文件名仅通过 `module=费用管理-账户充值.html` 参数兼容，`store-coin` 仅作为旧路由 key 兼容。
- 原型不发起真实支付、扣款或退款。

## 2. 页面结构

### 2.1 顶部提示

在充值内容上方横跨双栏展示提示条，使用浅蓝背景、蓝色描边及蓝色信息图标，正文为黑色；其中“充值金额不支持退款，请理性充值。”使用危险红色。文案固定为：

> 提示：1、充值金额不支持退款，请理性充值。2、企业内所有成员购买/续费设备时可共享账户余额。3、为防止您的临期设备因余额不足而错过自动续费，当您充值完成后，系统会对企业下已开启自动续费且在24小时内即将过期的设备进行续费。

### 2.2 云币余额

- 左侧业务区顶部显示“云币余额（元）”、当前余额和刷新入口；余额为 Mock 值，数字使用等宽字体。
- 余额卡采用参考图的浅蓝渐变背景和右侧云币意象，正文保持清晰可读。
- 标题右侧放置“？”帮助图标，鼠标悬停或键盘聚焦显示“关于云币”气泡，保留云币换算、使用范围和充值/消费记录查询说明。

### 2.3 充值金额与支付

- 字段显示为“充值金额：”，金额卡片组排列在标签右侧；窄屏时允许换行但不得溢出。
- 金额卡片提供 500、1000、2000、5000 元和自定义金额，支持实时更新赠送云币、实际到账及右侧订单详情。
- 优惠券、支付宝/微信支付方式、更多支付展示与“立即支付”沿用页面现有交互；确认和扫码仅为原型演示。
- 支付金额、优惠券与支付方式选择后，订单详情同步更新应付金额；支付入口不得产生真实交易。

## 3. 验收标准

1. 导航与文件名均显示“云币充值”；`index.html?page=billing-recharge` 能加载新文件并保持唯一 SystemFrame，旧入口可兼容跳转。
2. 顶部提示完整展示三条规则，蓝色图标/描边/浅底、黑色正文和红色不可退款文案符合设计规范。
3. 余额卡在桌面和平板下呈现浅蓝背景，刷新入口与标题右侧的帮助气泡可用。
4. “充值金额：”与金额卡片组同行，自定义金额、优惠券、支付方式和订单详情联动有效，窄屏无横向溢出。
