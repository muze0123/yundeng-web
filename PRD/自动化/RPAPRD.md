# RPA 产品需求文档

## 1. 文档信息

- 产品：云登 PC 端
- 模块：RPA
- 页面文件：`Prototype/RPA.html`
- 需求依据：`YunLogin图片文字索引.tsv` 中 `RPA/` 目录 21 张截图
- 设计依据：`claude.md`、`design.md`、`Prototype/设计系统.html`
- 数据声明：任务名称、环境、模板、执行日志和时间均为脱敏 mock 数据，不代表当前账号真实数据。

## 2. 产品目标与目标用户

RPA 为运营人员、自动化配置人员和团队管理员提供本地自动化流程创建、模板获取、任务计划和运行日志查看能力。用户可通过拖拽或导入流程 JSON 生成任务流程，将流程分配给浏览器环境，并在本机客户端登录状态下执行自动化。

## 3. 功能范围与优先级

| 优先级 | 功能 |
| --- | --- |
| P0 | 任务模板列表、搜索、分组、启动、移动分组、复制和删除 |
| P0 | 创建任务流程、操作选项、流程步骤、导入、导出、调试、其他设置 |
| P0 | 分配环境、异常处理、任务完成后行为、删除确认 |
| P0 | 模板市场分类、模板详情、立即获取 |
| P1 | 计划管理空态、暂停计划入口 |
| P1 | 任务日志筛选、运行结果、日志详情 |
| P1 | 分组管理、创建分组、任务线程总数设置 |

不在本期范围：真实执行 RPA、跨设备同步、真实打开目标网站、真实点赞/评论/发布、真实文件下载、真实计划任务调度落库。

## 4. 关键事实与边界

- 截图明确提示：RPA 为本地设备执行，需软件启动并登录，产生的数据只存储在本地，不会跨设备同步。
- 任务模板主列表显示创建流程数为 4，分页为 50 条/页。
- 模板市场显示流程模板数约 23，分类包含全部、Twitter、Facebook、TikTok、Amazon、YouTube、LinkedIn、Etsy、Mercari、Poshmark、Other。
- 计划管理截图为空态，不能推断已有计划任务数据；原型默认展示空态，可提供创建计划说明。
- 任务日志截图显示多条异常结果，并可查看执行日志详情。
- 删除 RPA 任务流程后 30 天内可去回收站恢复。

## 5. 页面结构

页面复用云登管理中心 App Shell，侧栏高亮 RPA。业务区分为四个一级页签：

1. 任务模板：我的任务流程列表、批量选择、搜索、移动分组、分组管理、设置、启动。
2. 模板市场：模板分类、模板卡片、服务详情、立即获取。
3. 计划管理：计划列表、暂停计划、空态和创建计划入口说明。
4. 任务日志：运行结果筛选、日志列表、日志详情弹窗。

创建任务流程使用编辑器布局：

- 左侧：操作选项与关键词搜索，分类为页面操作。
- 中间：任务流程步骤列表，显示步骤数量上限 100。
- 右侧：任务基础信息、分配环境、导入/导出、调试、其他设置和任务完成后行为。

#### 5.1.5 响应式与溢出规则

- ≥1280px 编辑器使用左中右三栏；列表页展示完整表格。
- 768-1279px 编辑器右栏可折叠为抽屉；列表表格横向滚动。
- ＜768px 编辑器默认全屏单栏分步，左栏和右栏通过底部/侧边抽屉打开。

## 6. 任务模板

### 6.1 列表与筛选

- 支持全部状态筛选、关键词搜索、全选和多选。
- 表格字段：选择、任务名称、备注、分组、已选择环境、执行类型、操作。
- 行操作：启动、复制模板、删除。
- 批量操作：移动分组、删除。
- 搜索无结果展示空态。

### 6.2 启动流程

- 启动前必须分配至少一个环境；可选择普通任务、计划任务、优先执行。
- 分配环境弹窗支持分组树、环境列表、已选环境、清空已选、跳过分配和确定分配。
- 原型仅更新本页状态，不调用本地客户端、不打开浏览器、不访问外部网站。

### 6.3 分组与设置

- 创建分组必填分组名称，长度 0/30。
- 分组管理支持搜索、添加、修改、删除和批量删除。
- 移动分组支持选择多个任务并指定目标分组。
- 设置项包含任务线程总数，截图值为 3。

## 7. 创建任务流程

- 必填字段：任务名称、选择分组。
- 异常处理：跳过或中断。
- 操作选项包含新建标签、关闭标签、关闭其他标签、切换标签、访问网站、刷新页面、页面后退、页面截图、经过元素、下拉选择器、元素聚焦、点击元素、输入内容、滚动页面。
- 支持导入流程 JSON，导入内容为追加或替换。
- 支持导出流程 JSON，但原型只生成演示提示。
- 支持调试，但原型不执行真实任务。
- 其他设置包含任务备注、无头浏览器、全屏、任务超时、启动参数。
- 任务完成行为包含清除标签、关闭浏览器、保留浏览器。
- 流程步骤上限为 100；超出应阻止继续添加。

## 8. 模板市场

- 分类筛选模板，支持查看详情。
- 模板卡片字段：名称、简介、提供方。
- 服务详情字段：名称、出品方、更新日期、内容简介、步骤简介、立即获取。
- 立即获取将模板复制到“任务模板”草稿或打开创建流程编辑器；原型只写入本地 mock 数据。

## 9. 计划管理

- 字段：计划名称、任务流程、环境序号、执行频率、执行时间、开始时间、结束时间、操作。
- 支持暂停计划入口。
- 当前截图为空态，原型默认展示“暂无数据，去其它的页面逛逛吧”，不编造真实已有计划。

## 10. 任务日志

- 支持按运行结果筛选。
- 表格字段：运行 ID、序号/ID、任务流程、运行结果、执行时间、完成时间、操作。
- 运行结果包含异常、成功、执行中等状态。
- 查看详情弹窗展示日志标题、时间线和耗时，例如启动浏览器、步骤异常、time。

## 11. 状态与异常

| 场景 | 响应 |
| --- | --- |
| 未填写任务名称 | 字段标红并提示请填写任务名称 |
| 未选择分组 | 字段标红并提示请选择分组 |
| 未选择环境启动 | 打开分配环境弹窗或提示先分配环境 |
| 流程步骤为空 | 展示空态并提示拖动左边操作选项添加 |
| 导入 JSON 格式错误 | 阻止导入并保留原流程 |
| 删除任务 | 二次确认，说明 30 天内可从回收站恢复 |
| 计划管理无数据 | 展示空态，不生成虚假计划 |

## 13. 安全、权限与审计

- RPA 启动、调试、导入、删除、计划变更均需权限控制和审计。
- 模板涉及社媒互动、发帖、评论、下载等动作时，正式执行前应遵守目标平台规则和账号授权边界。
- 原型不得真实打开网站、执行自动化、写入本地文件或发出外部请求。
- 任务日志中的环境序号、账号和设备信息需要脱敏展示。

## 15. 验收标准

1. 四个页签可切换，当前项高亮且内容状态独立。
2. 任务模板列表由不少于 4 条 mock 数据驱动，搜索、全选、多选、移动分组有效。
3. 创建任务流程编辑器可添加步骤、导入 JSON、打开设置、切换异常处理和任务完成行为。
4. 分配环境弹窗可选择环境并更新已选状态。
5. 模板市场可分类筛选，详情弹窗包含内容简介、步骤简介和立即获取。
6. 计划管理默认展示空态，不伪造真实计划。
7. 任务日志展示异常记录，并可查看详情。
8. 删除任务必须二次确认并说明 30 天回收站恢复。
9. 所有执行、调试、导出和获取动作均为原型演示，不触发真实本地自动化或外部请求。
10. 业务标注从 1 连续编号、默认隐藏，弹窗打开时仅展示弹窗范围标注。
