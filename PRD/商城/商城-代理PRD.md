# 商城产品需求文档

> 产品：YunLogin PC 端
> 模块：商城 · 代理
> 事实来源：`YunLogin图片文字索引.tsv` 中"商城-代理"截图索引、`Prototype/商城-代理.html`
> 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`
> 价格说明：本文与原型中的价格、折扣和活动日期均为截图快照或 Mock 演示值，不代表当前真实报价

## 1. 产品目标

商城代理为用户提供全球家庭住宅代理、云平台代理和动态代理的统一购买入口。页面在高密度配置下持续展示订单试算结果、优惠和风险提示，使用户在支付前能够明确核对商品、地区、时长、数量和最终金额。

## 2. 用户与权限

- 团队管理员：购买代理、管理购物车并提交支付。
- 采购成员：配置商品并加入购物车；支付是否可用由团队权限控制。
- 普通成员：查看商品，不能使用团队资金支付。
- 系统：提供商品库存、动态价格、优惠券和订单试算。

## 3. 页面结构

复用统一 App Shell。商城业务区采用顶部 Tab：代理、套餐、购物车。代理页采用"左侧配置 + 右侧粘性订单摘要"。

页面必须展示合规提示：产品不提供翻墙服务；代理资源由第三方提供；用户应遵守适用法律法规，不得用于违法犯罪或侵害他人权益。海外代理仅允许在合规网络环境或完成实名认证后使用。

| 地区与号段选择 | 配置表单第一区 | 搜索输入、当前地区 chip、9 列地区选择 grid、号段选择（随机/自定义） | grid 列数响应式：≥1279px 9列、≥768px 4列、＜768px 2列 | 切换地区清空号段和资源 |

#### 3.1.4 响应式与溢出规则

- ≥1280px 使用左配置右摘要双栏布局，摘要 sticky。
- 768-1279px 保持双栏布局，缩小非核心间距。
- ＜768px 改为单列，配置项单列，订单摘要显示在提交区上方，底部提交栏改为垂直堆叠。

## 4. 代理购买配置字段

### 4.1 代理类型

| 代理类型 | 说明 |
|---|---|
| 电商社媒主推 | 精选电商/社交媒体场景代理，国家与城市联动 |
| 全球家庭住宅-静态 | 静态住宅代理，随机或自定义号段 |
| 云平台-静态 | 云平台代理（阿里云/华为云等），按月计费 |
| 快速检索购买 | 快速检索并直接购买特定资源 |

### 4.2 地区与号段

| 字段 | 规则 |
|---|---|
| 代理地区 | 国家与城市联动；提供热门地区快捷入口和搜索 |
| 代理号段 | 随机分配或自定义购买；自定义只展示支持号段选择的商品 |

### 4.3 代理资源

| 字段 | 规则 |
|---|---|
| 代理资源 | 按地区、类型与号段筛选；展示资源名和月价 |
| 无库存 | 资源卡片显示"已售罄"标签并禁用点击 |

### 4.4 购买配置

| 字段 | 规则 |
|---|---|
| 购买数量 | 正整数 stepper，受库存和单次限购约束 |
| 购买时长 | 1、3、6、12 个月；折扣由试算接口返回 |
| 优惠券 | 仅展示满足门槛、商品和有效期的优惠券 |
| 自动续费 | 开启后选择 1、3 或 12 个月周期；需提示账户余额 |

### 4.5 支付方式

| 支付方式 | 规则 |
|---|---|
| 支付宝 | 展示支付宝图标 |
| 微信支付 | 展示微信支付图标 |
| 账户云币 | 展示余额和刷新按钮；余额不足时显示充值入口 |

### 4.6 联动规则

- 切换代理类型或地区后重新加载资源并清空不兼容的号段、资源与优惠券。
- 价格、时长、数量、优惠券变化后调用订单试算，更新订单金额、折扣、优惠券抵扣和实付金额。
- 无库存资源禁用并显示原因。
- "加入购物车"保存当前配置；相同 SKU、地区、号段、时长和续费配置可合并数量。
- "立即购买"先校验购买须知，再进入支付确认弹窗；原型止于确认前。

## 5. 订单摘要与金额规则

订单摘要在配置区滚动时保持粘性。金额统一保留两位小数并使用等宽字体：

`实际应付 = 订单金额 - 折扣优惠 - 优惠券抵扣`

前端仅展示试算结果，不自行决定最终价格。提交订单必须携带 `quote_id`、价格版本和幂等键；报价过期时重新试算并让用户确认变化。

## 6. 支付确认与安全边界

- 用户必须勾选《代理购买须知》后才能提交。
- 明确提示代理类数字商品一旦下单不能退换。
- 原型不调用真实支付、不创建真实订单，只展示确认弹窗和模拟二维码。
- 支付密码、二维码、完整订单号和实名信息不得写入日志或埋点。
- 支付过程中禁止重复提交；关闭页面后可在费用管理查询真实订单状态。
- 倒计时归零（15 分钟）自动关闭支付弹窗。

## 7. 状态与异常

- 商品加载失败：保留已选配置并提供重试。
- 地区无资源：展示空态并推荐其他城市。
- 库存变化：标记资源不可用，重新选择。
- 优惠券失效：移除抵扣并解释原因。
- 试算失败：禁止下单，保留配置。
- 报价过期：刷新金额并要求再次确认。
- 云币不足：禁止云币支付并提供充值入口。

## 8. 接口建议

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/store/proxy-products` | 查询代理商品与库存 |
| GET | `/api/store/regions` | 查询国家、城市与热门地区 |
| GET | `/api/store/traffic-packages` | 查询动态代理（住宅）流量包 |
| POST | `/api/store/quotes` | 统一订单试算 |
| GET | `/api/store/coupons` | 查询可用优惠券 |
| GET/POST/DELETE | `/api/store/cart` | 管理购物车 |
| POST | `/api/store/orders` | 创建订单，携带幂等键 |
| POST | `/api/store/orders/{id}/payment-intents` | 创建支付意图 |

## 9. 埋点

- `store_tab_view`：proxy / plan / cart。
- `store_proxy_type_select`：proxy_type、region。
- `store_resource_select`：resource_id、price_bucket。
- `store_quote_result`：success、amount_bucket、coupon_used。
- `store_add_cart`：product_type、quantity_bucket、success。
- `store_buy_now_click`：source、payment_method。
- `store_checkout_blocked`：reason。
- 禁止记录代理地址、明细地理位置。

## 10. 验收标准

1. 代理、套餐、购物车三个 Tab 可切换，状态互不污染。
2. 代理类型、地区、资源、数量、时长、优惠券和续费配置真实联动订单摘要。
3. 加入购物车可新增/合并商品，角标与金额实时更新。
4. 未同意购买须知不可立即购买或结算。
5. 支付只到确认弹窗前（含模拟二维码和倒计时），不创建真实订单。
6. 所有价格均标记为演示试算，最终金额以后端为准。
7. 单文件可预览，无本地资源依赖，JavaScript 无语法错误。
