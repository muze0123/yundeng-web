# 商城产品需求文档

> 产品：YunLogin PC 端
> 模块：商城 · 购物车
> 事实来源：`Prototype/商城-购物车.html`
> 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`
> 价格说明：本文与原型中的价格、折扣和活动日期均为截图快照或 Mock 演示值，不代表当前真实报价

---

## 1. 产品目标

商城购物车为用户提供代理、套餐商品的统一结算入口，支持多商品批量选择、数量调整、优惠券切换和结算。页面实时统计已选商品的应付金额和子订单数，并支持从代理页或套餐页合并商品后统一支付。

## 2. 用户与权限

- 团队管理员：批量选择商品并提交结算。
- 采购成员：管理购物车商品；结算是否可用由团队权限控制。
- 普通成员：查看购物车，不能使用团队资金支付。
- 系统：提供商品状态校验、角标实时更新和结算统计。

## 3. 页面结构

复用统一 App Shell。商城业务区采用顶部 Tab：代理、套餐、购物车。购物车页采用"购物车表格 + 结算摘要"。

页面必须展示合规提示：产品不提供翻墙服务；代理资源由第三方提供；用户应遵守适用法律法规，不得用于违法犯罪或侵害他人权益。

#### 3.1.4 响应式与溢出规则

- ≥1800px：购物车列表列宽自适应，删除按钮紧贴行末。
- 1400–1799px：列宽弹性收缩，下拉框随容器宽度自适应。
- ≤1399px：改为上下双栏，结算摘要显示在购物车列表上方（order: -1）。
- ≤767px：购物车行简化为 2 列（商品信息 + 操作），其余信息换行。
- 表格横向滚动：只在表格容器内滚动，不带动页面整体横向滚动。

## 4. 购物车商品管理

### 4.1 分组规则

| 分组 | 商品类型 | 行内容特征 |
|---|---|---|
| 全球家庭住宅-静态 | 普通代理 | 时长下拉 + 数量 + 优惠券 + 金额 |
| 动态代理（住宅） | `orderTypeCode === 'dynamic_proxy'` | 容量 + 有效期 + 优惠券 + 金额 |
| 动态住宅流量包 | `orderTypeCode === 'traffic_package'` | 容量 + 有效期 + 优惠券 + 金额 |
| 云平台套餐 | 套餐类型 | 时长下拉 + 数量 + 优惠券 + 金额 |

### 4.2 商品状态

| 状态 | 代码 | 表现 | 是否可结算 |
|---|---|---|---|
| 正常 | `valid` | 正常展示，可选可改 | ✅ |
| 库存紧张 | `low-stock` | 正常展示，可选 | ✅（需提示） |
| 价格已变动 | `price-changed` | 正常展示，已选时禁用结算 | ❌ |
| 已售罄 | `sold-out` | 正常展示，已选时禁用结算 | ❌ |
| 报价已过期 | `quote-expired` | 正常展示，已选时禁用结算 | ❌ |

### 4.3 操作规则

| 操作 | 规则 |
|---|---|
| 全选 | 仅选中 `valid` 和 `low-stock` 商品；失效商品不被选中 |
| 分组全选 | 同上范围 |
| 单选 | 失效商品 checkbox 禁用 |
| 数量调整 | 仅对 `valid` 和 `low-stock` 商品可操作；范围 1–50 |
| 时长切换 | 1 个月 / 3 个月（8折）/ 12 个月（4折）；触发金额重算 |
| 优惠券切换 | 未选择 / 满 100 减 50 / 专享减 20；触发金额重算 |
| 删除 | 即时删除，无需二次确认 |
| 批量删除 | 仅删除已选商品 |
| 清空失效 | 删除所有 `sold-out`、`price-changed`、`quote-expired` 商品 |
| 结算 | 仅统计已选有效商品；失效商品可查看但不可结算 |

### 4.4 金额计算

```
商品实付 = 单价 × 数量 - 折扣优惠 - 优惠券抵扣
订单合计 = Σ 已选有效商品实付
```

## 5. 支付方式

| 支付方式 | 规则 |
|---|---|
| 支付宝支付 | 展示支付宝图标 |
| 微信支付 | 展示微信支付图标 |
| 账户云币支付 | 展示余额（¥300 Mock）；余额不足时显示充值入口 |

## 6. 订单确认弹窗

- 展示已选商品数量、应付金额。
- 原型只演示支付前确认，不会创建真实订单或发起扣款。
- 用户点击确认后弹窗关闭，不跳转到支付页面。

## 7. 状态与异常

- 购物车为空：展示空状态插图和引导文案"可从商城代理或套餐页面添加商品"。
- 商品失效后：有效商品仍可选，失效商品保留在列表中但不可结算。
- 角标实时更新：Tab 角标显示已选商品数量（仅统计有效商品）。
- localStorage 持久化：购物车商品、选中状态、分组折叠状态由 localStorage 记忆。

## 8. 接口建议

| 方法 | 路径 | 用途 |
|---|---|---|
| GET/POST/PATCH/DELETE | `/api/store/cart` | 管理购物车（CRUD） |
| POST | `/api/store/quotes` | 批量试算 |
| GET | `/api/store/coupons` | 查询可用优惠券 |
| POST | `/api/store/orders` | 创建订单，携带幂等键 |
| POST | `/api/store/orders/{id}/payment-intents` | 创建支付意图 |

## 9. 埋点

- `store_tab_view`：proxy / plan / cart。
- `store_cart_item_select`：item_id、item_type、checked。
- `store_cart_quantity_change`：item_id、qty_after。
- `store_cart_duration_change`：item_id、duration_after。
- `store_cart_coupon_change`：item_id、coupon_id。
- `store_cart_delete`：item_id。
- `store_cart_checkout_click`：item_count、payment_method。
- `store_cart_checkout_blocked`：reason（失效商品）。

## 10. 验收标准

1. 三个 Tab 可切换，购物车的选中状态和商品数量角标实时更新。
2. 全选/分组全选/单选逻辑正确；失效商品不被选中。
3. 数量调整、时长切换、优惠券切换均触发金额实时重算。
4. 失效商品（已售罄/价格变动/报价过期）不可结算但保留在列表中。
5. 删除、批量删除、清空失效均正确更新列表和角标。
6. 结算仅统计已选有效商品。
7. 购买须知未勾选时提交按钮禁用。
8. 订单确认弹窗正常打开和关闭，不创建真实订单。
9. localStorage 刷新后保留购物车状态和分组折叠状态。
10. 窄屏（≤1399px）上下双栏布局正常；表格横向滚动正常。
11. 单文件可预览，无本地资源依赖，JavaScript 无语法错误。
