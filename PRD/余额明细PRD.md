## 1. 需求概述

### 1.1 页面定位、场景与目标

余额明细是“费用管理”下的独立只读列表页，位于“云币充值”二级菜单下方。用户可查询充值、支出和兑换记录，核对每笔金额及交易后的账户余额，并导出当前查询范围。充值与支付不在本页发起；相邻“云币充值”页面承接充值操作。本页没有页内“云币充值 / 余额明细”顶部 Tab。

| 场景 | 入口与动作 | 可观察结果 | 异常 / 恢复 |
| --- | --- | --- | --- |
| 默认查看 | 点击费用管理 → 余额明细 | 展示 Mock 列表、搜索、筛选、导出和分页 | 无匹配记录时展示空行文案 |
| 核对单笔 | 输入交易单号、订单号或操作人并提交搜索 | 在选定搜索范围内匹配，回到第 1 页 | 清空输入恢复仅受已提交筛选约束的列表 |
| 条件查询 | 打开筛选抽屉，设置交易类型、项目、交易时间并确认 | 三类条件与搜索取交集，更新筛选角标 | 取消不提交草稿；逆序时间阻止提交 |
| 导出结果 | 对非空查询结果点击“导出” | 下载当前搜索和筛选命中的全部 Mock 记录 | 0 条时不下载并提示“暂无可导出的余额明细” |

**原型验收目标：**上述四条路径及第 10 章用例可重复执行；不把演示记录、导出或按钮点击当作真实资金流水成功。生产指标的基线、目标、周期和 Owner 尚无依据，见第 12 章。

### 1.2 范围与非目标

| 范围内：当前原型 | 范围外：当前原型 | 生产依赖 |
| --- | --- | --- |
| 只读列表、关键词搜索、抽屉筛选、日期时间范围、分页、CSV 下载、空状态和交互标注 | 真实账务请求、实时余额同步、退款、充值、流水详情、编辑/删除、批量操作、异步导出任务 | 权限、接口、数据时区、导出限额和审计策略待确认 |

```text
  └─ 筛选抽屉：交易类型 / 项目 / 交易时间 → 重置 / 确认提交
```

## 3. 页面与交互规格

### 3.1 页面布局与组件

| 区域 | 展示与布局 | 交互 / 状态 |
| --- | --- | --- |
| 业务内容 | 模块内容区四边留白，单个白色圆角区块；不再显示页内顶部 Tab | 内容不足一屏时区块填满可用高度，超出时跟随内容增长 |
| 工具栏 | 左侧“导出”，右侧统一搜索框和“筛选”按钮 | 按钮有 hover；搜索和筛选保持各自草稿/已提交语义 |
| 表格 | 按第 3.2 节顺序展示；所有列左对齐、长数据不换行，外层横向滚动 | 行 hover 有反馈；无行内详情、排序、勾选或批量操作 |
| 分页器 | 表格下方，共享 `YDPager` | 默认 10 条/页，可选 10、20、50；显示页码、总数、跳页入口 |
| 筛选抽屉 | 模块视口右侧 480px，窄屏占满可用宽度，内容区独立滚动 | 遮罩、关闭按钮及 Esc 可关闭；背景列表不可交互；关闭后焦点回触发器 |
| 标注 | “显示标注”开关与编号说明弹窗 | 仅供原型讲解，不属于正式业务数据 |

### 3.2 列表字段

| 顺序 | 表头 | Mock 字段 | 类型 / 展示规则 | 示例 |
| --- | --- | --- | --- | --- |
| 1 | 交易单号 | `no` | 字符串，完整展示，等宽字体 | `TX20260810A102` |
| 2 | 订单号 | `order` | 字符串，完整展示，等宽字体 | `YL2026081014201801` |
| 3 | 交易类型 | `type` | 枚举：充值、支出、兑换 | `充值` |
| 4 | 交易时间 | `time` | `YYYY-MM-DD HH:mm:ss`，等宽字体 | `2026-08-10 14:20:18` |
| 5 | 项目 | `project` | 文本，见第 3.4 节下拉取值 | `云币在线充值` |
| 6 | 金额 | `amount` | 表格用 `¥` 和两位小数；正数前加 `+` 并使用 success 色，负数使用 danger 色 | `+¥500.00` |
| 7 | 账户余额 | `balance` | 交易记录对应的余额，`¥` + 两位小数；不与“金额”合并 | `¥826.80` |
| 8 | 操作人 | `user` | Mock 名称或“系统”；人名保持当前页面的脱敏展示 | `张**` |

Mock 初始 8 条种子记录，另生成 16 条演示记录，总计 24 条；包括充值、支出、兑换和六类项目。表格不执行额外排序，遵循数组当前顺序；真实余额口径、交易时区与金额存储单位不由 Mock 推定。

### 3.3 搜索框

- 复用公共层 `YDSearchBox`，占位文案“请输入关键词，多个用中文逗号分隔”。范围菜单顺序固定为“全局搜索、交易单号、订单号、操作人”；**全局搜索只覆盖后三个字段**，不匹配项目、交易类型、金额、时间或余额。
- 输入非空文字先形成草稿，不立即筛选。选择范围、按 Enter 或点击搜索按钮后提交；若范围菜单打开，提交当前高亮项。方向键切换高亮，Esc 收起，失焦或点击外部收起但不提交草稿。
- 关键词按中文逗号 `，` 分词、去两侧空白、不区分大小写；在选定范围内任一词为包含匹配即命中。清空输入或点击清空按钮时撤销已提交关键词，范围恢复“全局搜索”，回第 1 页；搜索与已提交筛选条件取交集。

### 3.4 筛选抽屉

| 条件 | 控件与选项 | 默认 / 匹配 |
| --- | --- | --- |
| 交易类型 | 下拉：全部、充值、支出、兑换 | 默认“全部”；选中时精确匹配 `type` |
| 项目 | 下拉：全部项目、云币在线充值、静态住宅代理、CDKEY 兑换、环境套餐升级、设备自动续费、动态住宅代理 | 默认“全部项目”；选项由当前 Mock 记录的项目去重生成，选中时精确匹配 `project` |
| 交易时间 | 双月日期范围 + 开始/结束时间 | 两端均可留空；选定侧按包含边界过滤 `time`，时间选项半小时递进并含 `23:59` |

- 时间选择器支持前后月及前后年切换，默认以 2026 年 8 月为起始视图；已有日期时从已选月份打开。选择开始/结束日期及时间后，需点选择器内“确定”才写回抽屉草稿；选择器“取消”不写回，选择器“清空”只清选择器草稿。
- 交易时间起点晚于终点时，选择器“确定”保持打开并显示错误状态；若抽屉“确认提交”检测到逆序区间，则不提交，显示“开始时间不能晚于结束时间”、标红触发器并弹出同文案警告提示。仅一侧日期时按该侧边界过滤；开始时间默认 `00:00`，结束时间默认 `23:59`，结束边界包含 `23:59:59`。
- 打开抽屉时从已提交条件回填。底部“重置”只清当前草稿，不关闭、不立即改变列表或角标；“确认提交”通过校验后应用三个条件并回第 1 页。点遮罩、关闭按钮或 Esc 则舍弃未提交修改。
- 筛选角标只计算偏离默认值的已提交条件，交易类型、项目、时间范围各计 1；搜索不计入角标。提交筛选与搜索匹配取交集；原先交易单号、订单号不再是抽屉条件。

### 3.5 分页、空态与导出

- 先过滤后分页；搜索提交或筛选确认回第 1 页，切换页码或每页条数通过公共分页器更新会话状态。结果总数为 0 时显示“暂无符合条件的余额明细”，分页按组件的零结果状态处理。
- 导出结果范围是**当前已提交搜索和筛选后的全部记录**，不受当前页码和每页条数限制。非空时立即下载 `余额明细.csv`：UTF-8 BOM、CSV 单元格双引号转义、CRLF 行分隔；列顺序与表格一致，金额和余额为保留两位小数的数值字符串，CSV 不带表格中的 `¥` 或正数 `+` 前缀。
- 结果为 0 时不生成文件，警告提示“暂无可导出的余额明细”；非空时提示“已导出 N 条余额明细”。当前原型通过浏览器 Blob 在本地生成文件，不创建服务端导出任务。

### 3.6 状态与正式文案

| 状态 / 触发 | 可见文案与行为 |
| --- | --- |
| 搜索未提交草稿 | 列表与已提交条件保持不变 |
| 筛选抽屉标题 | `筛选余额明细`；底部按钮 `重置`、`确认提交` |
| 日期区间错误 | `开始时间不能晚于结束时间`；保持草稿，不更新列表 |
| 搜索或筛选无结果 | `暂无符合条件的余额明细` |
| 无结果点击导出 | `暂无可导出的余额明细`；不下载 |
| 非空结果点击导出 | `已导出 N 条余额明细`；下载同名 CSV |

提示由页面 Toast 展示，约 3 秒隐藏；同一提示再次触发时替换当前提示。原型没有网络加载、服务端失败及权限拒绝的 UI，不能将其表述为已实现状态。

## 4. 权限与数据安全

当前原型入口与导出按钮未进行角色鉴权，表格中的操作人使用 Mock 脱敏文本，导出沿用当前数据中的同一文本；金额和交易号也是演示值。生产环境的菜单查看权限、导出权限、团队数据隔离、导出审计和下载文件保留策略尚未确认；服务端鉴权不可由前端菜单可见性替代。

## 5. 数据模型与业务规则

| 规则编号 | 已实现的原型规则 |
| --- | --- |
| B-01 | 一条流水含 `no, order, type, time, project, amount, balance, user` 八个字段；页面只读，不改变账务状态 |
| B-02 | 关键词内部按“任一命中”匹配；搜索结果与交易类型、项目、开始时间、结束时间按 AND 组合 |
| B-03 | “全部”类型 / “全部项目”及空时间边界不约束该维度；边界包含选中时刻 |
| B-04 | 空值不可导出；非空导出作用于完整过滤结果，独立于分页 |
| B-05 | 搜索/筛选与页码、每页条数由 `sessionStorage` 会话键 `yundeng.billing.coin.transactions.v1` 保存；未提交的搜索或抽屉草稿不作为已应用条件 |

本页没有创建、审核、退款或余额变更操作，因此写操作状态机、并发编辑和写入幂等在当前原型中不适用。生产流水权威数据源及交易类型扩展映射待确认。

## 6. 接口与前后端契约

当前原型没有真实列表、余额或导出接口，也没有错误码、异步任务状态或服务端响应模型。生产实现至少需要评审：带权限和团队范围的列表查询、三类筛选与三字段搜索的服务端等价语义、分页/默认顺序、金额精度与时区、导出范围与限额、权限失败及系统失败的反馈。接口 Method、Path、字段命名及错误码均不得从本地 Mock 推断为已定稿。

## 7. 异常与边界

| 场景 | 当前原型行为 | 生产待确认 |
| --- | --- | --- |
| 零结果 | 表格展示空行，导出提示后不下载 | 首次无数据与条件无匹配是否区分 |
| 仅单侧时间 | 按所选起点或终点限制结果 | 服务端时区与边界精度 |
| 起点晚于终点 | 阻止提交并提示同文案错误 | 跨时区输入规则 |
| 筛选草稿取消 / 重置 | 取消不改变已应用条件；重置需再确认 | 无 |
| 请求失败、无权限 | 原型不发真实请求，也不模拟这两种状态 | 错误文案、重试和权限回退 |
| 768px 及较窄视口 | 表格横向滚动，抽屉最大宽度为视口宽度，日期双月布局窄屏改单列 | 最低支持浏览器与具体测试设备 |

## 8. 配置、埋点与审计

当前没有可运营配置、行为埋点或后端审计。生产版需确认页面访问、搜索提交、筛选确认、导出成功/失败的事件口径及采集边界；**不得采集原始交易号、订单号、操作人或导出文件内容**。导出审计主体、作用范围、时间和失败结果待权限方案一并定义。

## 9. 非功能性约束

- 视觉和交互沿用 `design.md` 的表格、搜索组件、筛选抽屉、分页和语义色；页面 HTML 自包含，复用已许可的公共层文件和原生 JavaScript，不新增构建步骤。
- 列表中的交易号、订单号、时间与金额使用等宽字体；动态数据渲染时进行 HTML 转义；金额列以语义色区分收支，但仍保留正负号，不能仅靠颜色表达。
- 目标视口为桌面及 768px 平板；表格外层横向滚动，不挤压列；抽屉和日期选择器应可键盘操作并有清晰焦点与标签。
- 生产性能目标、容量上限、真实数据保留周期和浏览器最低版本未在当前原型中定义，见第 12 章。
