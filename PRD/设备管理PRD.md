# 代理管理产品需求文档

> 产品：YunLogin PC 端  
> 模块：代理管理  
> 事实来源：`YunLogin图片文字索引.tsv` 第 26–41 行及对应截图  
> 复用参考：`PRD/编辑浏览器PRD.md` 的代理工作台、`Prototype/编辑浏览器.html`  
> 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`

## 1. 产品目标

代理管理统一承载平台代理、自有代理和代理 API 三类资源，支持检索、检测、授权、绑定环境、续费和安全删除。用户应能快速判断代理的可用性、到期风险和使用范围，并在执行会影响多个浏览器环境的操作前获得明确风险提示。

## 2. 用户与权限

| 角色 | 权限 |
|---|---|
| 团队管理员 | 查看和维护全部代理，授权成员，绑定环境，续费和删除 |
| 代理管理员 | 添加/编辑自有代理与代理 API，检测、备注、分配环境 |
| 普通成员 | 使用被授权代理，只查看脱敏凭证 |
| 只读成员 | 仅查看列表和日志，不可修改 |

账号、密码、提取链接等凭证默认脱敏；无“查看敏感信息”权限时不可通过页面源码、Toast、URL 或日志获取。

## 3. 页面结构

复用统一 App Shell。业务内容采用设计系统的两区块结构：

1. 筛选区：代理来源 Tab、来源对应筛选项、搜索、查询与重置。
2. 数据区：标题和操作栏、批量操作栏、数据表格、分页。

页面顶部展示过期提醒：“代理过期后将自动注销且不支持找回，请在到期前完成续费”。

#### 3.1.4 响应式与溢出规则

- ≥1280px 展示完整表格字段和一级批量操作。
- 768-1279px 筛选区换行，低频批量操作收纳到“更多”；表格横向滚动。
- ＜768px 左侧导航改为抽屉；表格可降级为卡片摘要，行级操作收纳到更多菜单。

## 4. 三类代理

### 4.1 平台代理

- 状态筛选：全部代理、运行中、即将到期、已过期、自动续费中。
- 平台类型筛选：全部、云平台、全球家庭住宅-静态、海外动态。
- 搜索：序号、代理名称、IP。
- 批量操作：续费、自动续费、设置标签、授权。
- 表格字段：序号、名称、代理信息、绑定环境、授权人、服务信息、标签、状态、自动续费、到期时间、操作。
- 空状态：显示“暂无数据”和“前往购买代理”。

### 4.2 自有代理

- 代理类型：全部、HTTP、HTTPS、SOCKS5。
- 地址类型：全部、IPv4、IPv6。
- 搜索：序号、名称、IP 或域名。
- 页面操作：添加代理、检测代理、设置备注、授权、删除。
- 表格字段：序号、名称、代理信息与检测时间、代理类型、地址类型、绑定环境、授权人、到期时间、备注、状态、操作。

### 4.3 代理 API

- 代理类型：全部、HTTP、HTTPS、SOCKS5。
- 搜索：序号、名称、提取链接。
- 页面操作：添加代理 API、检测代理、授权、删除。
- 表格字段：序号、名称、类型、提取方式、脱敏提取链接、检测结果、绑定环境、授权人、操作。

## 5. 核心交互

### 5.1 查询、选择与分页

- Tab 切换后保留各类型独立筛选草稿，查询结果回到第一页。
- 搜索框输入后显示清空按钮。
- 表头全选当前页，支持跨页多选；已选数量实时更新。
- 未选择代理时隐藏批量工具栏。
- 默认每页 20 条，支持 10/20/50/100 条及跳页。

### 5.2 添加自有代理

- 支持逐行批量录入，一次最多 500 条。
- 支持 HTTP、HTTPS、SOCKS5；未写协议时默认 HTTP。
- 支持 IPv4、域名、方括号包裹的 IPv6。
- 支持 `主机:端口:账号:密码{备注}` 等格式；备注不超过 40 字。
- IP 查询渠道默认 IP2Location。
- 可检测代理、仅添加检测成功项、校验重复项。
- 提交前展示总数、成功数和失败数；错误行不静默丢弃。

### 5.3 编辑代理

字段包括代理名称、类型、地址类型、IP/域名、端口、账号、密码、备注、到期时间和 IP 查询渠道。名称必填且不超过 100 字；端口为 1–65535。若已有绑定环境，需提示“修改代理将影响所有已绑定环境”。

### 5.4 检测代理

- 支持单条与批量检测。
- 状态依次为待检测、检测中、可用、不可用。
- 成功记录出口 IP、地区、延迟和检测时间；失败保留失败原因。
- 检测不自动修改代理或解绑环境。

### 5.5 分配环境

- 弹窗展示当前代理名称、IP 和已绑定数量。
- 支持分组和名称搜索、跨页多选、移除已选环境。
- 已绑定环境默认勾选；确定后以当前选择替换绑定集合。
- 明示风险：多个环境使用同一代理可能导致账号关联和网速变慢。

### 5.6 授权

- 可按所有成员、部门、角色筛选。
- 支持成员搜索、全选、跨页多选和清空已选。
- 确定后将所选代理授权给所选成员；没有成员时阻止提交。

### 5.7 设置备注与标签

- 备注最多 40 字，可对一个或多个代理批量设置。
- 标签最多 30 字，可多选或新建；删除标签不删除代理。

### 5.8 查看与操作日志

详情抽屉展示代理基础信息、检测结果、绑定环境和操作日志。日志包含操作时间、类型、内容和操作人，不记录密码、提取链接与完整账号。

### 5.9 续费与自动续费

- 续费前展示代理、时长、原到期时间、新到期时间和金额。
- 自动续费支持开启/关闭；开启前确认扣款账户和周期。
- 已过期但尚未注销的代理可续费；已注销代理不可恢复。

### 5.10 删除

- 删除前列出代理序号及已绑定环境。
- 有绑定环境时仍需明确确认，不得静默解绑。
- 删除后 30 天内可在回收站恢复；平台代理的供应商注销规则优先于回收站。

## 6. 数据模型

| 字段 | 规则 |
|---|---|
| id | 唯一序号，等宽字体 |
| source | platform / owned / api |
| name | 1–100 字 |
| protocol | HTTP / HTTPS / SOCKS5 |
| addressType | IPv4 / IPv6 / domain / dynamic |
| endpoint | IP/域名及端口，凭证分离存储 |
| status | available / unavailable / expiring / expired / renewing |
| environments | 已绑定环境数组 |
| authorizedTo | 已授权成员数组 |
| expiresAt | 可为空；等宽字体 |
| remark | 0–40 字 |
| tags | 多标签 |
| lastCheckedAt | 最后检测时间 |

## 7. 状态与异常

- 加载失败：保留筛选条件并提供重试。
- 空数据：根据类型展示购买或添加入口。
- 检测失败：显示原因，不删除代理。
- 重复代理：开启校验重复项时阻止添加并定位行号。
- 授权失败/分配失败：保留临时选择并允许重试。
- 并发修改：通过版本号或 ETag 提示数据已变化并刷新。
- 批量操作部分失败：展示成功/失败数量与可下载明细。

## 8. 接口建议

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/proxies` | 查询代理列表 |
| POST | `/api/proxies/owned/batch` | 批量添加自有代理 |
| POST | `/api/proxies/api` | 添加代理 API |
| PATCH | `/api/proxies/{id}` | 编辑、备注、标签、自动续费 |
| POST | `/api/proxies/check` | 批量检测 |
| PUT | `/api/proxies/{id}/environments` | 替换绑定环境集合 |
| PUT | `/api/proxies/authorizations` | 批量授权 |
| POST | `/api/proxies/renew` | 批量续费 |
| DELETE | `/api/proxies` | 批量软删除 |
| GET | `/api/proxies/{id}/logs` | 查询操作日志 |

## 9. 安全与非功能要求

- 密码与提取链接加密传输、加密存储，前端默认不回填明文。
- 批量操作携带幂等键，禁止重复提交。
- 桌面 ≥1280px、平板 ≥768px 可用；表格只在自身容器横向滚动。
- 页面使用内联 Mock 数据驱动，至少 8 条，覆盖可用、不可用、临期、过期和续费中状态。
- 交互标注默认隐藏，仅标注业务内容；弹窗/抽屉使用作用域隔离。

## 10. 验收标准

1. 三个代理 Tab 能切换独立筛选、表格字段与操作栏。
2. 搜索、类型/地址/状态筛选、清空、重置和分页真实生效。
3. 单选、全选、跨页多选和批量工具栏状态正确。
4. 添加与编辑代理具备名称、地址、端口、重复项和字符校验。
5. 批量检测会更新状态与最后检测时间，并保留失败原因。
6. 分配环境、授权、备注、日志和删除流程可演示。
7. 删除明确展示绑定环境与 30 天恢复规则。
8. 页面数据、账号、代理凭证均脱敏。
9. 标注编号从 1 连续，默认隐藏，弹窗打开后无页面标注穿透。
10. 单文件可预览、无本地资源依赖、JavaScript 无语法错误。
