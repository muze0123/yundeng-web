## 0. 给 AI 编码工具的执行指令

先完整阅读本 PRD、`design.md` 与 `claude.md`，再生成 `系统框架.html`。附件图片是**页面整体布局、组件层级、可见菜单与视觉结构的最高优先级依据**；当它与文字规范冲突时，按以下顺序决策：

1. 图片决定页面骨架、可见组件、菜单层级、组件相对位置与信息密度；
2. 本 PRD 决定交互、状态、数据流、权限与边界；
3. `design.md` 决定颜色、字体、圆角、间距、阴影、通用组件外观；
4. `claude.md` 决定 HTML 技术栈、单文件交付、导航、Mock 数据和 Portal 标注实现方式。

首版必须使用语义化 HTML5、Tailwind CSS CDN、Lucide CDN 和原生 JavaScript（ES6+），不引入 React、Vue、jQuery 或其他未授权库。页面双击即可预览；数据为内联 Mock 数据；页面必须可交互且控制台无错误。后续 React + TypeScript 重构时，保留本 PRD 的状态模型、事件契约与组件边界，不依赖原生 JS 的全局变量。

> **明确覆盖规则：** 图片中“团队”和“自动化”两组菜单同时展示子菜单；因此系统框架默认支持多个一级分组同时展开。此规则覆盖 `claude.md` 中“展开其他一级菜单自动收起当前菜单”的原型约定。若未来需要手风琴模式，应通过 `sidebar.multiExpand=false` 配置切换，而不是改写菜单数据结构。

## 1. 需求概述

### 1.1 页面定位

系统框架是云登 PC 端所有登录后业务页面的统一应用壳，负责提供环境与团队相关能力的全局入口、当前路由上下文、消息与帮助入口、内容承载区域、跨页面提示和智能助手入口。它不承载环境管理、代理管理、商城、费用、团队、插件、自动化等业务页面本身的表格、表单或详情逻辑；这些页面以路由内容的形式注入主内容区。

本框架必须让用户无论身处哪个业务页面，都能稳定完成：识别当前模块、切换功能、发起“新建浏览器”、查看通知、进入新手帮助、切换语言、打开智能助手，以及在加载、无权限或路由失败时获得明确反馈。

### 1.2 用户与场景

| 场景 ID | 角色与触发 | 主路径 | 成功结果 |
|---|---|---|---|
| S-01 | 已登录成员首次进入系统 | 加载会话与导航配置 → 默认进入环境管理 → 渲染三栏框架 | 当前路由、菜单高亮、账户/通知信息一致，内容区显示目标页面或其加载态 |
| S-02 | 成员切换模块 | 点击无子菜单项或二级菜单 | 经离开保护校验后切换路由，更新页面标题、菜单高亮、内容区数据 | 仅一个叶子菜单为当前页，地址与内容一致 |
| S-03 | 成员展开导航分组 | 点击“团队”或“自动化”分组标题 | 切换对应子菜单列表的展开状态，不发生路由跳转 | 已展开的其他分组保持展开，符合图片结构 |
| S-04 | 成员需要创建浏览器 | 点击左上“新建浏览器” | 框架发出创建意图并打开由业务模块提供的创建流程 | 业务模块接管创建，不在 App Shell 内伪造成功结果 |
| S-05 | 成员处理全局信息 | 点击通知、帮助/新手教程、语言或智能助手 | 打开对应 Popover、页面、抽屉或外链；框架维护关闭与焦点返回 | 不破坏当前页面筛选、滚动与未保存数据 |
| S-06 | 权限或网络异常 | 路由加载后发现无权限、网络失败、会话过期 | 内容区显示对应状态；必要时触发一次全局提示与恢复入口 | 用户知道原因、下一步与数据是否保留 |

### 1.3 范围与非目标

**本期包含**：三栏布局、顶部全局栏、可配置左侧菜单、主内容 Router Outlet、侧栏折叠与响应式行为、全局通知与语言入口的框架交互、智能助手入口、Toast / Dialog / Drawer 容器、页面级 Loading / Empty / Error 状态、Mock 会话与导航数据、Portal 标注系统接入。

**本期不包含**：环境列表/详情、代理购买、商城下单、团队成员 CRUD、API 或 RPA 的业务逻辑；会员权益真实支付；通知中心真实消息数据；智能助手问答引擎；服务端鉴权接口。上述能力仅定义入口、状态和适配器契约。

## 2. 信息架构与页面整体结构

### 2.1 图片对齐的页面骨架

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ Sidebar（固定左侧） │ TopBar（固定顶部，位于主内容列）                         │
│  新建浏览器          ├────────────────────────────────────────────────────────┤
│  环境管理（当前）    │ MainContent / Router Outlet                             │
│  代理管理            │                                                        │
│  商城                │  由当前业务路由注入内容；框架初始仅显示内容承载占位。 │
│  费用管理            │                                                        │
│  团队                │                                                        │
│   ├ 团队管理         │                                                        │
│   ├ 成员管理         │                                                        │
│   ├ 分享转移         │                                                        │
│   ├ 日志管理         │                                                        │
│   └ 账号设置         │                                                        │
│  插件管理            │                                                        │
│  自动化              │                                                        │
│   ├ API              │                                                        │
│   └ RPA              │                                                        │
│  回收站              │                                                        │
│  帮助 / 设置 / 智能助手（底部）                                                  │
└───────────────────────────────────────────────────────────────────────────────┘
```

除登录页与原型导航页外，所有后台页面均复用此 App Shell。主内容区不是业务“空状态”：在框架层，它是路由内容插槽；只有目标路由已成功加载且返回零条可展示数据时，才由目标页面显示业务 Empty。

TopBar 高 56px，固定于主内容列顶部，不使用底部描边，统一使用 `0 4px 12px rgba(26,29,36,.10)` 向下阴影与正文分层。业务页面若提供固定底部操作栏，应使用方向相反的向上阴影，并为正文预留操作栏高度。
