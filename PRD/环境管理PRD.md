# 环境管理 PRD

## 1. 文档信息

- 产品：云登 / YunLogin PC 端
- 模块：环境管理
- 页面类型：桌面端环境列表与批量运维工作台
- 事实来源：`/Users/zhangbin/Desktop/YunLogin/环境管理` 内截图及 `YunLogin图片文字索引.tsv` 第 376–415 行
- 设计约束：`claude.md`、`design.md`、`Prototype/设计系统.html`

## 2. 产品目标

环境管理为用户提供浏览器环境的统一查看、搜索、启动、关闭和配置入口。页面应支持单环境精细操作与多环境批量运维，在不离开列表上下文的前提下完成分组、标签、代理、账号、Cookie、缓存、授权、分享、RPA 等高频任务。

## 3. 目标用户与权限

| 角色 | 核心诉求 | 权限边界 |
|---|---|---|
| 团队管理员 | 管理全部环境、成员授权与配置 | 可执行全部操作及危险操作 |
| 环境管理员 | 批量维护代理、标签、分组和账号 | 不可变更团队级配置 |
| 普通成员 | 启动和使用被授权环境 | 仅操作本人或已授权环境 |

无权限操作应禁用并提供原因说明；原型默认展示团队管理员视角。

## 4. 页面结构

### 4.1 系统框架

复用统一 App Shell：左侧导航、顶部栏、通知、帮助、语言、账号、智能助手。当前菜单高亮“环境管理”。业务页面不为系统框架生成交互标注。

### 4.2 筛选区

- 分组：默认“全部分组”，支持选择已有分组。
- 搜索：支持按序号、名称、账号、IP、备注、标签搜索；输入后可一键清空。
- 查询：应用当前筛选条件。
- 重置：恢复全部分组与空搜索条件。

### 4.3 数据区

- 标题：环境列表，并显示当前结果数量。
- 主操作：新建浏览器、分组管理、标签管理、批量导入、刷新、列表字段设置。
- 批量操作栏：选中至少一个环境后展示，包含启动、关闭、RPA、授权、分享、转移、窗口同步与更多操作。
- 表格默认字段：勾选、星标、序号、分组、名称、账号、代理信息、备注、标签、授权人、创建时间、操作。
- 分页：支持上一页、下一页、页码、每页条数与跳页；统计文案与表格处于同一卡片。

## 6. 核心交互

### 6.1 查询与列表

1. 用户输入关键字或选择分组。
2. 点击“查询”，前端按多字段过滤并回到第一页。
3. 点击“重置”恢复默认结果。
4. 点击列头“名称”或“创建时间”切换升降序。
5. 点击星标即时切换置顶状态；已置星记录优先展示。
6. 字段设置支持勾选显示列、置星标列与恢复默认。

### 6.2 选择与批量操作

- 表头勾选当前页全部环境；行勾选更新已选数量。
- 未选中环境时批量操作栏不显示。
- 启动：将可启动环境置为启动中，完成后置为运行中；模拟失败时展示失败原因弹窗。
- 关闭：二次确认后将运行中环境置为已关闭。
- RPA：选择模板与执行类型；计划任务必须填写计划名称，开始时间至少晚于当前时间 10 分钟。
- 授权、分享、转移、修改代理、编辑备注、设置标签、设置星标均对所选环境生效。

### 6.3 行级操作

行内显示“启动/关闭”和“更多”。更多菜单包括：修改环境、修改指纹、转移分组、修改标签、修改备注、环境信息、修改账号、修改代理、环境授权、编辑 Cookie、缓存管理、技术协助、克隆环境、Cookie Robot、清除 Cookie、删除环境。

### 6.4 弹窗与抽屉

| 子流程 | 关键字段/行为 | 校验与反馈 |
|---|---|---|
| 分组管理 | 搜索、新建、授权、修改、删除、批量转移 | 名称 1–30 字，不可重复 |
| 标签管理 | 创建、搜索、批量删除 | 标签 1–30 字，不可重复 |
| 修改代理 | 本机网络、平台代理、自有代理、代理 API | 代理格式及网络检查 |
| 修改账号 | 平台、名称、账号、打开网址 | 名称必填，网址逐行校验 |
| 编辑名称/备注 | 名称、备注 | 100/200 字计数 |
| 设置标签/转移分组 | 多选标签、目标分组 | 至少选择一项 |
| 缓存管理 | 本地缓存、本地快照、云端快照 | 删除需确认；云端最多保留 30 天 |
| 编辑 Cookie | JSON / Netscape 文本 | 格式错误阻止提交 |
| Cookie Robot | 网站列表、频率、设备、开关 | 最多 10 个网址，须含协议 |
| 分享环境 | 缓存数据、团队 ID、时长、备注、图片 | 团队 ID 每行一个；图片 jpg/png ≤2MB |
| 技术协助 | 备注、图片 | 明示配置共享范围 |
| 克隆环境 | 数量 | 不得超过套餐剩余额度 |
| 删除环境 | 二次确认 | 删除后 30 天内可从回收站恢复 |
| 清除 Cookie | 高风险确认 | 明示可能影响账号风控安全 |

## 7. 状态与异常

- 加载中：表格骨架或按钮 loading，禁止重复提交。
- 空结果：展示“暂无符合条件的环境”，保留重置入口。
- 启动失败：列出序号、名称与失败原因，不把失败记录置为运行中。
- 网络检查失败：保留原代理信息并提示重试。
- 权限不足：操作禁用并说明需联系团队管理员。
- 危险操作：删除环境、清除 Cookie、关闭运行中环境均须二次确认。

## 8. 可用性与非功能要求

- 适配 1280px 以上桌面与 768px 平板；表格窄屏横向滚动。
- 列表 8–15 条真实感 mock 数据，敏感账号与代理凭证脱敏。
- 所有按钮、菜单、表格行具备 hover/focus 状态；Esc 可关闭顶层浮层。
- 原型为单 HTML 文件，Tailwind CDN + Lucide CDN + 原生 JavaScript，无构建步骤。
- 有交互或业务规则的功能必须提供 Portal 交互标注；标注默认隐藏，编号从 1 连续排列。

## 9. 验收标准

1. 搜索、分组查询、重置、排序、星标、分页均真实改变列表。
2. 多选后展示批量工具栏，批量启动/关闭能更新状态。
3. 行级更多菜单可打开对应业务弹窗或抽屉，取消、遮罩、Esc 可关闭。
4. 名称、备注、计划任务、危险操作等关键流程具有校验或确认。
5. 列表字段设置能即时控制表格列并恢复默认。
6. 侧栏当前项为环境管理，页面可跳转新建/编辑浏览器及系统框架。
7. 交互标注默认隐藏，显示后不被表格或弹窗裁剪；弹窗开启时只展示弹窗内标注。
8. 页面无英文装饰标题、无 emoji 图标、无静态堆叠数据、控制台无错误。
