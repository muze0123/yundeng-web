## 1. 背景、目标与范围

### 1.1 问题定义

跨境店铺、社媒和广告运营团队需要集中保存多个平台账号，并将账号复用到不同浏览器环境。若账号只能在环境编辑页临时录入，会产生重复录入、凭据散落、绑定关系不可追踪、批量迁移效率低和敏感信息越权暴露等问题。

账号管理应作为团队级资产中心，使有权限成员能够完成：

1. 查找和识别平台账号；
2. 新增或批量导入账号；
3. 将账号绑定到一个或多个环境并查看绑定关系；
4. 在不暴露历史明文凭据的前提下更新资料；
5. 锁定凭据、批量维护备注、软删除并审计关键动作。

### 1.2 产品目标

| 目标 | 可观察口径 | 不应误判为成功的行为 |
|---|---|---|
| 提升账号资产录入效率 | 创建成功数、导入成功数、导入部分失败数 | 仅点击“添加账号”或选择文件 |
| 提升账号与环境关联效率 | 绑定请求中成功建立的账号—环境关系数 | 仅打开绑定 Modal 或勾选环境 |
| 降低凭据暴露风险 | 明文敏感字段零埋点、零 URL、零前端日志；越权接口拒绝率 100% | 仅在 UI 中把密码框设为掩码 |
| 提高维护可追溯性 | 创建、编辑、锁定、绑定、解绑、导入、删除均可通过审计日志追踪 | Toast 显示成功但服务端未落库 |

业务指标的基线和提升目标需在上线前由产品与数据负责人基于真实埋点确定；本文不编造当前转化率或耗时基线。

### 1.3 用户与核心场景

| 用户 | 核心任务 | 主要风险 |
|---|---|---|
| 团队创始人/管理员 | 管理全部账号、凭据权限、批量导入和删除 | 大批量误操作、敏感数据泄露 |
| 获授权的运营成员 | 查看可见账号、绑定负责的环境、维护非敏感资料 | 对象级越权、误解锁定语义 |
| 只读/无账号权限成员 | 查看被授权摘要或完全不可见 | 前端隐藏但接口仍泄露数据 |

### 1.4 In scope

- 账号列表、平台与关键词检索、重置、刷新、分页；
- 添加账号、编辑账号、凭据锁定；
- 批量导入三步流程：上传、数据本地校验、完成导入；
- 多选账号后批量绑定环境；
- 查看单账号已绑定环境详情，并进入调整绑定；
- 批量编辑备注；
- 单个/批量软删除账号；
- 空、加载、错误、无权限、部分成功与并发冲突状态；
- 权限、安全、审计、埋点和前后端契约。

### 1.5 Out of scope

- 平台库、平台图标和登录网址的后台配置；
- 浏览器环境的创建、启动、指纹和代理配置；
- 回收站页面本身、彻底删除和恢复交互；
- 自动登录执行结果、平台风控结果和 2FA 实时口令生成；
- CSV/XLS/XLSX 解析库选型及服务端存储加密实现细节；
- 跨团队账号分享或转移。

## 2. 信息架构与用户流程

### 2.1 页面入口与返回

- 入口：左侧导航“团队 > 账号管理”。
- 当前页：一级“团队”和二级“账号管理”同时高亮。
- 批量导入为同一 App Shell 下的子视图；返回后保留进入导入前的筛选、页码和勾选状态，导入成功后清除勾选并刷新列表。
- Modal/Drawer/Dialog 关闭后，焦点回到触发入口；按 `Esc` 仅关闭最上层浮层。

### 2.2 主流程

```text
账号管理列表
├─ 查询/重置/刷新 → 列表或搜索空态
├─ 添加账号 → 校验 → 创建成功 → 插入列表首行
├─ 编辑账号 → 仅回填非敏感字段 → 保存 → 更新当前行
├─ 批量导入
│  ├─ 上传文件 → 文件级校验
│  ├─ 数据本地校验 → 修正文件或继续导入有效行
│  └─ 创建导入任务 → 完成/部分失败 → 返回列表
├─ 选择 N 个账号
│  ├─ 绑定环境 → 选择环境 → 批量建立关系
│  ├─ 编辑备注 → 统一覆盖备注
│  └─ 删除 → 二次确认 → 进入回收站
└─ 查看详情 → 已绑定环境 Drawer → 调整绑定
```

### 2.3 状态保留规则

| 场景 | 保留 | 重置 |
|---|---|---|
| 查询 | 当前筛选 | 页码回到 1 |
| 重置 | 每页条数 | 平台、关键词、页码和选择 |
| 打开/关闭 Modal | 列表筛选、页码、滚动位置 | 未提交的 Modal 草稿 |
| 导入成功返回 | 每页条数 | 筛选回到默认、页码 1、选择清空 |
| 浏览器刷新 | URL 中允许保留非敏感筛选 | 勾选、浮层、敏感输入和导入文件 |

## 3. 页面与区域需求

### 3.1 账号管理列表

**页面目的：**集中查询、识别和批量维护团队平台账号。  
**呈现形态：**复用 `Prototype/系统框架.html` 的 App Shell。  
**布局与滚动：**主内容区 `p-4`；筛选区与数据区垂直堆叠、间距 16px；App Shell 承载卡片无外描边；表格最小宽度 1420px，窄屏仅表格横向滚动，页面不横向溢出。

```text
┌──────────────────────────── 筛选区 ────────────────────────────┐
│ 账号管理                                                       │
│ 平台 [全部平台]   搜索 [名称、账号或备注]   [查询] [重置]       │
└────────────────────────────────────────────────────────────────┘
┌──────────────────────────── 数据区 ────────────────────────────┐
│ 账号列表   已选 N 项      [添加] [批量导入] [绑定] [备注] [删除] [刷新] │
│ □ 名称 平台 账号 所属环境 备注 添加时间 最后修改时间 添加人 操作     │
│ ...                                                            │
│                                            分页                 │
└────────────────────────────────────────────────────────────────┘
```

#### 3.1.1 筛选区

| 组件 | 类型 | 默认值 | 行为 | 状态 |
|---|---|---|---|---|
| 页面标题 | Heading | 账号管理 | 始终展示 | 不参与标注范围外的系统导航 |
| 平台 | 可搜索 Select | 全部平台 | 选择后不自动请求，点击查询与关键词按 AND 生效 | 平台列表失败时可重试；不影响关键词查询 |
| 关键词 | Search Input | 空 | 匹配名称、账号和备注；去除首尾空格；有值显示清空按钮 | 最大 100 字；不得将账号全文写入 URL、埋点或日志 |
| 查询 | Primary Button | — | 发起查询、页码回到 1、清空勾选 | 请求中禁用防重复 |
| 重置 | Default Button | — | 平台恢复“全部平台”、关键词清空、页码回到 1 | 列表重新加载 |

#### 3.1.2 工具栏

| 操作 | 前置条件 | 系统行为 | 禁用/失败 |
|---|---|---|---|
| 添加账号 | `account.create` | 打开添加账号 Modal | 无权限隐藏；提交中禁用 |
| 批量导入 | `account.import` | 进入批量导入子视图 | 无权限隐藏 |
| 绑定环境 | 已选 1–300 个账号且有 `account.bind` | 打开绑定环境 Modal | 未选择时禁用并显示原因 |
| 编辑备注 | 已选 1–300 个账号且有 `account.update` | 打开批量备注 Modal | 未选择时禁用 |
| 删除 | 已选 1–300 个账号且有 `account.delete` | 打开确认 Dialog | 未选择时禁用；部分受保护账号需逐项返回失败原因 |
| 刷新 | `account.read` | 保留筛选和页码重新加载；清空选择 | 加载时图标旋转且按钮禁用 |

选择范围只包含用户明确勾选的账号，不允许把“当前筛选全部结果”隐式当作批量作用范围。跨页勾选保留，并在工具栏展示“已选 N 项”。

#### 3.1.3 表格字段

| 列名 | 字段 key | 展示与格式 | 空值 | 权限/安全 |
|---|---|---|---|---|
| 选择 | `selected` | 单行复选框；表头复选仅切换当前页 | — | 不可选对象的复选框禁用并说明原因 |
| 名称 | `name` | 单行省略，悬停展示全文 | `-` | 非敏感 |
| 平台 | `platform_name` | 平台图标/色块 + 名称 | 不允许为空 | 非敏感 |
| 账号 | `login_account_masked` | 按类型脱敏；锁定时显示锁图标 | `-` | 接口不得返回无权限用户的明文 |
| 所属环境 | `environment_count` | `0` 时为“绑定环境”；大于 0 为“查看详情（N）” | 0 | 点击查看/调整关系，不展示环境凭据 |
| 备注 | `remark` | 最多展示两行，超长省略 | `-` | 非敏感，但不进入通用行为埋点 |
| 添加时间 | `created_at` | `YYYY-MM-DD HH:mm:ss` | `-` | 以团队时区展示 |
| 最后修改时间 | `updated_at` | 同上 | `-` | 服务端时间为准 |
| 添加人 | `creator_name` | 成员昵称 | `已离职成员` | 对成员无查看权限时显示脱敏昵称 |
| 操作 | — | 编辑、删除 | — | 依据对象级权限逐项展示 |

默认排序为 `created_at desc, account_id desc`。V1 不开放用户自定义排序，避免把截图未出现的能力伪装为现有功能。

#### 3.1.4 分页

- 默认 20 条/页，与页面图片一致；可切换 10、20、50 条/页。
- 页码规则严格遵守 `design.md`：总页数大于 7 时折叠；显示跳页、总数和当前页。
- 切换每页条数回到第 1 页；页码变化保留筛选和跨页选择。
- 搜索无结果显示“未找到符合条件的账号”；默认无数据显示“暂无账号”，并提供“添加账号”入口。

### 3.2 添加/编辑账号 Modal

**呈现形态：**760px Modal，最大宽度 92vw；标题分别为“添加账号”“编辑账号”。  
**布局：**标题栏、可滚动内容区、底部操作区；字段标签 90px 右对齐，控件宽 400px；移动端标签移到控件上方。

#### 3.2.1 表单字段

| 名称 | key | 类型/上限 | 必填 | 默认/回填 | 校验与行为 | 安全规则 |
|---|---|---|---|---|---|---|
| 平台 | `platform_id` | 可搜索 Select | 是 | 新增为空；编辑回填 | 为空提示“请选择平台” | 只提交 ID |
| 名称 | `name` | string ≤100 | 否 | 新增空；编辑回填 | 去首尾空格；用于管理区分 | 非敏感 |
| 账号 | `login_account` | string ≤200 | 否 | 新增空；编辑仅显示脱敏占位 | 空值允许；输入即视为覆盖更新 | 不回填明文；不记录日志/埋点 |
| 锁定账号 | `credential_locked` | boolean | 否 | 新增关闭；编辑回填状态 | 控制凭据查看与编辑范围，不影响绑定和使用 | 修改需 `account.credential.lock` 并审计 |
| 密码 | `password` | secret ≤256 | 否 | 永不回填 | 留空不修改；输入可临时显隐；提交后清空 | TLS；服务端加密存储；禁止持久化到前端 |
| 备注 | `remark` | string ≤100 | 否 | 编辑回填 | 计数 `x/100`；允许换行时按实际字符计数 | 不进入行为埋点 |
| 2FA 密钥 | `totp_secret` | secret ≤256 | 否 | 永不回填 | 留空不修改；只做基本 Base32 形态提示，不回显历史值 | 同密码；不在前端生成或存储口令 |

> 平台仅是截图中明确标记的必填项。若某个平台后续配置 `account_required=true`，前后端可按平台动态要求账号，但不得在缺少平台配置契约时全局强制。

#### 3.2.2 操作规则

| 编号 | 动作 | 系统行为 | 成功 | 失败/取消 |
|---|---|---|---|---|
| AM-A01 | 打开添加 | 创建隔离的空白草稿 | — | 关闭不改变列表 |
| AM-A02 | 打开编辑 | 拉取可见的非敏感详情和 `version` | — | 详情失败保留列表并提示重试 |
| AM-A03 | 保存 | 客户端校验后提交；按钮 loading；使用幂等键/版本号 | Toast“账号添加成功”或“账号信息已更新”；刷新对应行 | 保留非敏感输入；敏感字段不写入错误；冲突提示刷新 |
| AM-A04 | 取消/关闭/遮罩/Esc | 有输入变化时提示是否放弃；无变化直接关闭 | 焦点回触发器 | 不提交任何草稿 |

编辑账号时，账号、密码和 2FA 的空值统一表示“不修改”，不得解释为“清空”。清空敏感字段属于独立高风险能力，本期不提供。

### 3.3 批量导入

**呈现形态：**App Shell 内容区整页子视图。  
**步骤：**上传导入文件 → 数据本地校验 → 完成导入。  
**已核实限制：**支持 XLS、XLSX、CSV；文件最大 10MB；单次最多 300 行。

#### 3.3.1 第 1 步：上传导入文件

- 提供“下载导入模版”入口；下载结果必须来自版本化模板接口，不能由前端临时拼接。
- 支持点击选择和拖拽上传；文件选择后展示文件名、大小、移除和重新选择。
- 文件级校验失败不进入下一步，正式文案：
  - `仅支持 xls、xlsx、csv 格式`
  - `文件大小不能超过 10MB`
  - `导入数据不能超过 300 行`
- 未选择合法文件时“下一步”禁用；“返回账号管理”不保存文件。

#### 3.3.2 第 2 步：数据本地校验

| 校验 | 规则 | 错误级别 |
|---|---|---|
| 表头 | 必须匹配模板版本；未知列允许忽略但给出警告 | 阻断/警告 |
| 平台 | 必填；需匹配平台 ID/标准名称 | 阻断 |
| 名称 | ≤100 | 阻断 |
| 账号 | 允许为空；若平台要求账号则不可为空 | 阻断 |
| 密码/2FA | 长度与基本格式校验；结果页不显示原值 | 阻断 |
| 备注 | ≤100 | 阻断 |
| 锁定状态 | 仅允许模板枚举 `是/否` | 阻断 |
| 重复行 | 同团队、同平台、标准化账号相同视为疑似重复 | 警告；是否覆盖由用户明确选择 |

- 展示总行数、有效、错误、警告数量和逐行原因；敏感单元格始终以 `••••••` 展示。
- 存在错误时默认禁用“开始导入”。用户可下载错误报告并返回第 1 步重新上传。
- 只有警告时允许继续，但必须明确选择“跳过重复”或“覆盖非敏感字段”；V1 默认跳过重复且不覆盖历史密码/2FA。

#### 3.3.3 第 3 步：完成导入

- 创建异步导入任务；服务端逐行处理并返回成功、跳过、失败数量。
- 完成态支持“返回账号管理”和“下载失败明细”。
- 部分失败不回滚已成功行；失败行可用同一模板修正后重新导入。
- 页面关闭后任务继续执行，可在任务中心追踪；原始上传文件和失败报告的保留期限见待确认项 O-04。

### 3.4 绑定环境 Modal

**呈现形态：**760px Modal；标题“绑定环境”。  
**作用对象：**已明确勾选的 1–300 个账号。  
**关系模型：**账号与环境为多对多；本次选中的每个账号都与提交的环境集合建立关系。

| 区域 | 内容与规则 |
|---|---|
| 摘要 | 展示“已选择 N 个账号”，最多列出前 3 个名称，不展示账号明文 |
| 筛选 | 分组下拉默认“全部分组”；搜索环境名称；两者按 AND 生效 |
| 表格 | 复选、序号、环境名称、分组、备注；默认 10 条/页 |
| 选择摘要 | 展示当前结果总数与已选环境数；支持跨页多选 |
| 提交 | 至少选择 1 个环境；按钮 loading 防重复 |

提交结果按账号—环境关系逐项返回：

- 已存在关系按幂等成功处理，不重复创建；
- 无环境权限、环境已删除或账号并发删除返回单项失败；
- 全部成功 Toast：`已为 N 个账号绑定 M 个环境`；
- 部分成功展示成功/失败统计和失败原因，不回滚成功关系。

### 3.5 已绑定环境详情 Drawer

**呈现形态：**右侧 800px Drawer。  
**入口：**所属环境列中的“查看详情（N）”。

- 标题展示账号名称和平台，不展示完整账号；
- 列表字段：环境名称、分组、状态、环境备注、绑定时间、绑定人；
- 支持关键词搜索、分页和刷新；
- 有 `account.bind` 权限时展示“调整绑定”，复用绑定环境 Modal；
- 本期不在详情 Drawer 内提供单条解绑，以避免引入截图和功能清单未证实的操作；如研发需提供，须先补充删除关系的确认、并发和审计规则。

### 3.6 批量编辑备注 Modal

- 标题“编辑备注”；展示前 1 个名称和“等 N 个”。
- 文本域 `maxlength=100`，实时计数 `x/100`。
- 确认后以同一值覆盖所有已选账号的备注；空字符串表示清空备注。
- 提交前文案明确：`将统一覆盖 N 个账号的原备注。`
- 部分成功时显示成功/失败数量并保留失败对象供重试。

### 3.7 删除确认 Dialog

- 单条标题：`确认删除当前账号吗？`
- 批量标题：`确认删除已选 N 个账号吗？`
- 副文案：`账号将进入回收站并保留 30 天；已绑定环境不会被删除。`
- 已绑定账号附加影响摘要：`其中 X 个账号已绑定环境，删除后这些环境将无法继续读取对应账号凭据。`
- “取消”为次按钮；“删除”为危险按钮；不要求输入对象名称。
- 删除成功后清空选择、刷新列表并提示可在回收站恢复。
- 服务端必须执行软删除，禁止列表接口继续返回已删除对象；绑定关系的恢复策略见 O-03。

### 3.8 正式文案

| 场景 | 文案 |
|---|---|
| 默认空态 | `暂无账号` / `添加平台账号后，可统一绑定到浏览器环境。` |

| 网络失败 | `网络异常，请检查网络后重试` |
| 版本冲突 | `账号已被其他成员修改，请刷新后重试` |
| 无权限 | `你暂无此操作权限` |

## 4. 权限、可见性与数据安全

### 4.1 权限矩阵

| 动作 | 权限点 | 团队管理员 | 获授权成员 | 只读成员 | 服务端要求 |
|---|---|---|---|---|---|
| 查看列表/详情 | `account.read` | 是 | 按数据范围 | 按配置 | 对象级鉴权与字段脱敏 |
| 新增 | `account.create` | 是 | 按配置 | 否 | 校验团队归属 |
| 编辑非敏感字段 | `account.update` | 是 | 按对象授权 | 否 | 乐观锁 |
| 更新敏感凭据 | `account.credential.update` | 是 | 按配置 | 否 | 独立鉴权、加密、审计 |
| 锁定/解锁凭据 | `account.credential.lock` | 是 | 默认否 | 否 | 记录前后状态，不记录凭据 |
| 批量导入 | `account.import` | 是 | 按配置 | 否 | 文件扫描、行级校验 |
| 绑定环境 | `account.bind` + `environment.read` | 是 | 两端均有权限 | 否 | 同时校验账号和环境数据范围 |
| 删除 | `account.delete` | 是 | 按配置 | 否 | 软删除、影响摘要、审计 |

### 4.2 敏感字段红线

1. 密码、2FA、完整账号不得进入 URL、localStorage、sessionStorage、通用埋点、控制台、错误监控、Toast 或审计详情。
2. 编辑接口永不返回密码和 2FA 明文；前端空值代表“不修改”。
3. 列表只使用服务端提供的 `login_account_masked`，不得在前端接收明文后再脱敏。
4. 导入预览和错误报告不得包含密码、2FA 原文；服务端日志仅记录行号、字段名和错误码。
5. 凭据锁定不能只依赖前端隐藏，读取与更新接口必须服务端拒绝越权访问。
6. DOM 中敏感输入在关闭 Modal、提交完成或离开导入流程后立即清空。

## 5. 数据模型、状态与业务规则

### 5.1 领域对象

| 对象 | 唯一标识 | 核心字段 | 关系 |
|---|---|---|---|
| `PLATFORM_ACCOUNT` | `account_id` | `team_id, platform_id, name, login_account_cipher, login_account_masked, password_cipher, totp_cipher, remark, credential_locked, version, deleted_at` | 属于一个团队；与环境多对多 |
| `PLATFORM` | `platform_id` | `name, icon_url, account_required, enabled` | 被账号引用 |
| `ENVIRONMENT` | `environment_id` | `name, group_id, status, remark` | 与账号多对多 |
| `ACCOUNT_ENV_BINDING` | `binding_id` | `account_id, environment_id, created_by, created_at` | 唯一键 `(account_id, environment_id)` |
| `ACCOUNT_IMPORT_TASK` | `task_id` | `file_version, total, success, skipped, failed, status` | 属于团队与操作者 |
| `RECYCLE_ITEM` | `recycle_id` | `object_type, object_id, deleted_at, purge_at` | 指向已删除账号 |

### 5.2 状态枚举

| 对象 | code | 展示 | 说明 |
|---|---|---|---|
| 凭据 | `unlocked` | 未锁定 | 仍需权限才能查看/更新 |
| 凭据 | `locked` | 已锁定 | 非授权角色不可查看或更新凭据 |
| 账号 | `active` | 正常 | 可查询、绑定和编辑 |
| 账号 | `deleted` | 已删除 | 仅回收站可见，等待恢复或清理 |
| 导入任务 | `queued` | 排队中 | 已受理未开始 |
| 导入任务 | `processing` | 导入中 | 返回服务端真实进度 |
| 导入任务 | `partial_fail` | 部分失败 | 成功行已落库，可下载失败明细 |
| 导入任务 | `success` | 导入完成 | 全部有效行完成 |
| 导入任务 | `failed` | 导入失败 | 未能创建任何账号或任务异常 |

### 5.3 业务规则

| 编号 | 规则 | 实现责任 | 验证 |
|---|---|---|---|
| AM-B01 | 筛选条件按 AND 组合；关键词在名称、账号检索索引和备注间按 OR 匹配 | 前后端 | 接口/E2E |
| AM-B02 | 账号可为空；平台始终必填；平台配置可附加动态必填规则 | 前后端 | 单测/E2E |
| AM-B03 | 一账号可绑定多个环境，一环境可绑定多个账号；重复关系幂等 | 后端 | 唯一键/接口测试 |
| AM-B04 | 锁定凭据不改变账号可用、绑定或删除状态 | 前后端 | 权限/E2E |
| AM-B05 | 批量操作只作用于显式勾选 ID，最大 300 个 | 前后端 | 边界测试 |
| AM-B06 | 删除为 30 天软删除；环境对象不随账号删除 | 后端 | 回收站/接口测试 |
| AM-B07 | 密码和 2FA 只允许覆盖更新，不允许读取明文 | 后端 | 安全测试 |
| AM-B08 | 批量导入逐行处理，部分成功不整体回滚 | 后端 | 异步任务测试 |

### 5.4 并发、幂等与一致性

| 场景 | 方案 | 用户可见结果 |
|---|---|---|
| 连续保存/绑定/删除 | 前端 loading 禁用；写请求携带 `Idempotency-Key` | 只产生一次结果 |
| 多人编辑同一账号 | `version` 乐观锁；冲突返回最新 `updated_at` | 提示刷新，不静默覆盖 |
| 重复绑定 | 数据库唯一键 + upsert 幂等 | 计入“已存在”，不报系统错误 |
| 批量部分失败 | 每对象/关系独立结果；成功不回滚 | 展示成功、失败、跳过数量 |
| 删除与绑定并发 | 删除状态优先，新增绑定失败 | 明确提示账号已删除 |
| 权限中途撤销 | 服务端 403；前端刷新权限与选择 | 保留可安全保留的非敏感草稿 |

## 6. 接口与前后端契约

> 路径为 V1 产品语义建议，需与正式 OpenAPI 对齐后实施；不得把本文路径当作已上线事实。

### 6.1 接口清单

| 场景 | Method & Path | 关键请求 | 关键响应 | 失败语义 |
|---|---|---|---|---|
| 账号列表 | `GET /api/v1/accounts` | `platformId,keyword,page,pageSize,sort` | `items,total,permissions` | `FORBIDDEN, INVALID_FILTER` |
| 账号详情 | `GET /api/v1/accounts/{id}` | `id` | 非敏感字段、脱敏账号、锁定状态、`version` | `NOT_FOUND, FORBIDDEN` |
| 新增账号 | `POST /api/v1/accounts` | 表单、`Idempotency-Key` | `accountId,version` | `VALIDATION_ERROR, DUPLICATE` |
| 编辑账号 | `PATCH /api/v1/accounts/{id}` | 变更字段、`version` | 更新摘要、`version` | `VERSION_CONFLICT` |
| 批量备注 | `PATCH /api/v1/accounts/remark` | `accountIds,remark` | `successItems,failedItems` | `PARTIAL_FAILURE` |
| 软删除 | `POST /api/v1/accounts/delete` | `accountIds` | `deleted,failed,purgeAt` | `PROTECTED_ENTITY, PARTIAL_FAILURE` |
| 平台列表 | `GET /api/v1/platforms` | `keyword,enabled=true` | `items` | `INTERNAL_ERROR` |
| 环境候选 | `GET /api/v1/accounts/bindable-environments` | `accountIds,groupId,keyword,page,pageSize` | 环境列表、已绑定摘要 | `FORBIDDEN` |
| 批量绑定 | `POST /api/v1/account-environment-bindings` | `accountIds,environmentIds` | `created,existed,failed` | `PARTIAL_FAILURE` |
| 绑定详情 | `GET /api/v1/accounts/{id}/environments` | 筛选、分页 | 绑定环境列表 | `NOT_FOUND, FORBIDDEN` |
| 导入模板 | `GET /api/v1/account-import/template` | `version` | 短时下载 URL | `ARTIFACT_EXPIRED` |
| 上传校验 | `POST /api/v1/account-import/validate` | multipart 文件、模板版本 | `validationId,summary,rowErrors` | `FILE_TOO_LARGE, INVALID_TEMPLATE` |
| 创建导入任务 | `POST /api/v1/account-import/tasks` | `validationId,duplicatePolicy` | `taskId,status` | `VALIDATION_EXPIRED` |
| 查询导入任务 | `GET /api/v1/account-import/tasks/{taskId}` | `taskId` | 进度、统计、报告 URL | `NOT_FOUND, ARTIFACT_EXPIRED` |

### 6.2 通用错误处理

| 错误码 | 前端行为 | 重试 | 正式文案 |
|---|---|---|---|
| `UNAUTHENTICATED` | 刷新令牌一次，失败后跳登录 | 一次 | `登录已失效，请重新登录` |
| `FORBIDDEN` | 关闭高风险浮层并刷新权限 | 否 | `你暂无此操作权限` |
| `VALIDATION_ERROR` | 字段级错误，不清空输入 | 否 | 使用服务端安全文案 |
| `VERSION_CONFLICT` | 保留非敏感草稿，允许刷新 | 否 | `账号已被其他成员修改，请刷新后重试` |
| `PARTIAL_FAILURE` | 展示统计与失败对象，不回滚成功项 | 可重试失败项 | `部分操作未完成，请查看失败原因` |
| `RATE_LIMITED` | 按 `retryAfter` 倒计时禁用 | 是 | `操作过于频繁，请稍后再试` |
| `INTERNAL_ERROR` | 保留非敏感输入，敏感输入由用户决定重新填写 | 幂等请求可重试 | `系统异常，请稍后重试` |

### 6.3 导入任务约定

- 前台可见时每 5 秒轮询；页面不可见时暂停，重新进入后恢复。
- `progress` 必须由服务端返回 0–100 整数，前端不得按时间估算。
- 失败报告 URL 使用短时签名，不写入埋点和错误监控。
- 校验结果与原始文件过期后必须重新上传，不允许复用过期 `validationId`。

## 7. 异常、边界与降级

| 场景 | 页面表现 | 系统处理 | 恢复 |
|---|---|---|---|

## 8. 配置、埋点、审计与监控

### 8.1 可运营配置

| key | 默认 | 规则 |
|---|---|---|
| `accountImportEnabled` | `true` | 可按团队灰度关闭导入入口 |
| `accountImportMaxRows` | `300` | 1–300；前后端一致 |
| `accountImportMaxBytes` | `10485760` | 10MB；前后端一致 |
| `accountBatchMaxSize` | `300` | 批量绑定、备注、删除上限 |
| `accountRecycleDays` | `30` | 与回收站全局策略一致 |

### 8.2 埋点

| 事件名 | 触发 | 允许属性 | 禁止采集 |
|---|---|---|---|
| `account_page_view` | 列表成功可见 | `role,source` | 账号、备注、密码、2FA |
| `account_query_result` | 查询完成 | `hasPlatform,hasKeyword,resultCount,durationMs` | 搜索原文 |
| `account_submit_result` | 新增/编辑完成 | `mode,result,errorCode,durationMs` | 任意表单原值 |
| `account_bind_result` | 绑定完成 | `accountCount,environmentCount,successCount,failedCount` | 对象名称和 ID 原值 |
| `account_import_result` | 导入终态 | `status,total,success,skipped,failed` | 文件名、文件内容、报告 URL |
| `account_delete_result` | 删除完成 | `count,successCount,failedCount` | 账号原文 |

### 8.3 审计

创建、编辑、锁定/解锁、批量备注、绑定、导入和删除均记录：`operatorId、operatorRole、teamId、targetType、targetIdHash、action、changedFieldNames、result、requestId、createdAt`。敏感字段只记录“password_updated / totp_updated”，不得记录前后值。

告警至少覆盖：导入任务失败率异常、凭据越权访问、批量删除异常增长、连续版本冲突和服务端返回敏感字段扫描命中。

| 类别 | 要求 | 验收口径 |

| 安全 | TLS、服务端 RBAC、对象级鉴权、加密存储、输出转义、文件扫描 | 安全测试 |
| 隐私 | 明文凭据零日志/零埋点；编辑接口不返回密码/2FA | 自动扫描 + 人工审计 |
| 可访问性 | label、键盘焦点、Esc、焦点恢复、非颜色唯一表达 | 键盘与读屏检查 |
| 兼容性 | 桌面端 1280px 以上完整布局；768px 平板可用；Chrome/Edge 当前稳定版 | 视觉与交互回归 |
| 可恢复性 | 写请求幂等；批量结果可追踪；软删除 30 天 | 接口/E2E |

## 11. 发布、灰度与回滚

| 阶段 | 内容 | 通过条件 | 回滚条件 |
|---|---|---|---|
| 上线前 | 权限初始化、模板版本、敏感字段扫描、软删除演练 | P0 验收全部通过；无明文泄露 | 任一安全红线失败 |
| 灰度 | 按团队开启新增/绑定，导入能力独立开关 | 写成功率、部分失败原因和审计可追踪 | 数据重复、越权或任务积压 |
| 全量 | 开启账号管理与导入 | 观察期内错误率符合服务端 SLO | 关闭功能开关，保留已创建数据 |

回滚优先关闭新写入和导入入口；已受理导入任务继续到终态或由服务端安全取消，不允许删除已成功导入账号来模拟回滚。
