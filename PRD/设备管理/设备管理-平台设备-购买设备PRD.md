## 1. 需求概述

### 1.0.1 页面定位

|定位维度|说明|
|---|---|
|页面职责|本页是设备商城「购买设备」子页面，供用户在**单页内**完成设备资源的选择（类型 → 地区 → 套餐 → 数量/时长/优惠券/续费/支付方式）并核对订单试算金额，最终「加入购物车」或「立即支付」。本页不承担购物车管理、不创建真实订单、不处理支付结果回调。|
|系统位置|入口为侧边栏「设备管理 → 购买设备」，路由 `index.html?page=store`；同一子页面内与「购物车」页签并列（`index.html?page=store&tab=cart`）。上游可带 `product_id` / `proxy_type` / `purchase` 深链参数带入预置选择；下游为购物车页与待支付订单弹窗。|
|核心决策|用户在此判断「选哪种类型的设备、落在哪个国家-城市、买哪一档套餐、买几个、买多久、用哪种支付方式」，并确认应付金额后决定是否下单。|
|边界|本页只做「选择 + 试算 + 提交意向」；真实下单、支付、退款、开票由费用管理（订单管理 / 账户充值 / 交易流水）与后端承接。套餐页与计价模拟页已无本页入口。|
|价值与风险|缩短设备选配路径，把地区、套餐、优惠、续费放在同一屏内可核对，降低误购与金额争议；错误操作后果为选错地区/套餐导致下单后不可退换（数字商品），因此必须在下单前显式确认《设备购买须知》。|

**可复制填写：**「购买设备页是设备商城中的配置型子页面，面向团队管理员与采购成员，在需要采购设备资源时完成「类型 → 地区 → 套餐 → 购买配置」四段式选配与订单试算。它承接设备管理入口与深链参数，输出购物车条目或待支付订单意向，核心决策是确定设备类型、地区、套餐与支付方式。本页不负责购物车管理、真实下单与支付结果处理；当用户未勾选《设备购买须知》或未选择套餐时，必须阻止继续下单并给出明确提示。」

### 1.1 背景与问题

- 当前流程：`团队管理员/采购成员` 在 `设备管理` 通过 `设备商城 → 购买设备` 完成设备选配与下单；页面此前为「代理购买」形态，含代理类型 Tab、号段选择、代理资源网格与购买配置标题文案。
- 已知问题：①「代理」术语已随全站改名统一为「设备」，旧 PRD 与页面文案不一致；②类型、地区、资源三段信息分散，地区参数与其他字段不对齐，高密度下难以横向核对；③资源卡片尺寸与行高不稳定，套餐区块下方留下大片空白；④「本地」类设备无对应入口与说明，用户不清楚本地网络的使用限制。
- 根因假设：页面结构沿用了早期「代理」业务模型（号段 / 流量包 / 快速检索购买），与当前「设备 + 套餐」的商品模型不匹配；字段未做字段化收敛（字段名右对齐 + 参数左对齐），导致视觉与规则双重分散。
- 本需求的解法：把配置区重构为「类型 / 地区 / 套餐 / 购买配置」四段式字段化布局，地区用「大陆 → 国家 → 城市」三行 chips 表达层级，资源收进「套餐：」字段并按 280×80 卡片网格展示，本地类型独立成支并配「特别提示」说明限制。

### 1.2 一句话目标与成功指标

**一句话目标：**在用户需要采购设备资源时，让其在单页内以「类型 → 地区 → 套餐 → 购买配置」四步完成选配并确认应付金额，同时把误购风险（未读须知、未选套餐、库存不足）在提交前拦截。

|指标|指标定义（分子/分母）|基线|目标|统计周期|数据来源|Owner|
|---|---|---|---|---|---|---|
|核心结果指标|进入购买设备页后成功进入待支付弹窗的会话占比|【】|【】|周|埋点 `store_buy_now_click` / `page_view`|【】|
|漏斗指标|类型选择 → 地区选择 → 套餐选择 → 加购/下单的转化率|【】|【】|周|埋点 `store_proxy_type_select` / `store_resource_select`|【】|
|质量护栏|「未选套餐」「库存不足」「未同意须知」三类拦截次数占比|【】|上限【】|周|埋点 `store_checkout_blocked`|【】|

**数据边界：**原型不接入真实支付与订单，`store_buy_now_click` 只代表站内意向，不得等同于支付成功；云币余额在本页为固定演示值（300），真实余额与扣减以后端为准。

## 5. 数据模型、业务规则与状态机

### 5.1 领域对象与关系

```Plaintext
设备类型（all/static/cloud/local）
  └─ 地区（大陆 → 国家 → 城市）  ※ local 类型不涉及地区
        └─ 套餐（proxyProducts：静态住宅 / 云平台 / 本地动态 / 本地静态）
              └─ 购买配置（时长 duration、数量 qty、优惠券 coupon、续费 renew、支付方式 payment）
                    └─ 试算结果（original / packageDiscount / coupon / total / available）
                          ├─ 加入购物车（localStorage 条目）
                          └─ 待支付订单（Mock 订单号 + 倒计时）
```

### 5.2 枚举与状态机

**类型 enum：**`all` 全部平台设备 / `static` 静态住宅 / `cloud` 云平台 / `local` 本地。
**支付方式 enum：**`alipay` / `wechat` / `coin`。
**页面状态机（配置维度）：**

```Plaintext
[默认：全部平台设备 · 美国-洛杉矶 · 未选套餐]
   │ 选套餐                    │ 切「本地」            │ 切「静态住宅/云平台」
   ▼                           ▼                       ▼
[已选套餐，可提交]  ← 选套餐 ← [本地：无地区，2 张卡片]  [保留/回落地区，套餐清空]
   │ 数量 > 库存 / 券失效 / 取消须知
   ▼
[不可提交：按钮禁用 + Toast 说明] → 修正后回到「已选套餐，可提交」
```

**待支付订单状态：**`pending`（弹窗打开，倒计时进行中）→ `cancelled`（倒计时归零自动关闭）或 `closed`（用户关闭）。原型不产生支付成功态。

### 5.3 业务规则清单

|编号|规则|
|---|---|
|R-01|套餐默认不选中；未选中时「加入购物车 / 立即支付」均禁用，摘要「类型-套餐」显示「待选择」。|
|R-02|套餐来源：本地类型 = 本地动态 + 本地静态；其他类型 = 全部平台设备（静态住宅 + 云平台）或按类型过滤（`type !== 'local'`）。|
|R-03|地区文案：本地类型显示「本地网络」；其他类型显示「{国家}-{城市}」（城市为空时显示「待选择」）。|
|R-04|可用性：`available = product.stock >= qty`；本地与「安哥拉」以外的地区均视为有资源，安哥拉展示「当前地区暂无可用资源，请选择其他地区。」。|
|R-05|原价 `original = 商品原价 × 数量 × 时长`；折后 `sale = 商品价 × 数量 × 时长 × 时长折扣系数`；折扣优惠 `packageDiscount = original - sale`。|
|R-06|优惠券：`10` 元券按面额直接抵扣；`20` 元券在 `sale < 100` 时置 0 并回退下拉（F-02）。|
|R-07|应付金额 `total = max(0, original - packageDiscount - coupon)`，统一保留两位小数并等宽字体展示。|
|R-08|数量恒为 1–50 的整数；动态类型恒为 1。|
|R-09|切换类型为本地：清空大陆/国家/城市与套餐；切换为其他类型时若此前无国家则回落默认地区。|
|R-10|切换大陆/国家/城市任一级：清空套餐并逐级重置下级选择。|
|R-11|地区搜索仅过滤国家与城市列表，不改变已选中的大陆；搜索期间隐藏「更多」按钮。|
|R-12|国家 > 6 或城市 > 6 时提供「更多/收起」，展开时两者同时展开（`regionExpanded` 共享）。|
|R-13|「美国」「洛杉矶」显示「推荐」角标。|
|R-14|加入购物车按 `type + name + spec + region` 去重，命中则数量累加（clamp 1–50）。|
|R-15|订单号格式 `YL` + `yyyyMMddHHmmss` + 4 位数字后缀（由毫秒与数量推导）。|
|R-16|待支付倒计时 29 分 49 秒（`29 * 60 + 49`），归零自动关闭弹窗并提示已取消。|

### 5.4 并发、幂等与一致性

- 弹窗打开期间重复点击不得创建多个实例；关闭后可重新打开，订单号重新生成。
- 加入购物车为本地写入，若 `localStorage` 不可用（如 `file://`）则静默失败，不阻塞页面。
- 真实环境提交订单须携带 `quote_id`、价格版本与幂等键；报价过期需重新试算并让用户确认变化。
- 前端试算结果不得作为最终价格，最终以服务端试算与库存判定为准。

## 7. 异常、边界与降级

|场景|表现与恢复|
|---|---|
|商品加载失败|保留已选类型与地区，套餐区提供重试；不得清空用户配置。|
|所选地区无资源|套餐区显示「当前地区暂无可用资源，请选择其他地区。」，按钮禁用。|
|库存变化|卡片置为不可用（`disabled`），重新选择套餐。|
|优惠券失效|抵扣置 0、下拉回退，并在明细中说明原因。|
|试算失败|禁止下单，保留全部配置。|
|报价过期|重新试算并展示金额变化，要求用户再次确认。|
|云币不足|真实环境禁止云币支付并提供充值入口；原型不校验。|
|页面刷新 / 切换页签返回|本页配置不持久化，回到默认态（全部平台设备 / 美国-洛杉矶 / 未选套餐）；购物车数据因写入 `localStorage` 而保留。|
|窄屏（≤850px）|单列布局；地区字段名与搜索框允许堆叠；套餐卡片按容器宽度自适应列数。|

## 9. 非功能性与技术约束

- 单文件可预览，无本地资源依赖（图片与图标走相对路径与图标库），JavaScript 无语法错误。
- 交互响应：字段变化到金额刷新应在同帧内完成（原型为同步试算）。
- 可访问性：类型/地区/支付方式使用 `role="group"` / `radiogroup` 与 `aria-pressed` / `aria-checked`；弹窗使用 `role="dialog"` + `aria-modal` 并管理焦点；Toast 使用 `role="status"`（危险提示 `role="alert"`）。
- 键盘可用：页签支持左右方向键；弹窗支持 Esc 关闭与 Tab 循环；搜索框 Enter 选中首个匹配项。
- 视觉约束：字段名右对齐（列宽 88px）、参数左对齐；字段名后统一补「：」；颜色与间距引用设计系统 token。
