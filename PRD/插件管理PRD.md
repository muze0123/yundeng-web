# 插件管理产品需求文档

## 1. 文档信息

- 产品：云登 PC 端
- 模块：插件管理
- 页面文件：`Prototype/插件管理.html`
- 需求依据：`YunLogin图片文字索引.tsv` 中 `插件管理/` 目录 17 张截图
- 设计依据：`claude.md`、`design.md`、`Prototype/设计系统.html`
- 数据声明：插件名称、下载量、版本、添加人和环境均为 mock 数据；第三方插件能力仅作原型展示。

## 2. 产品目标与目标用户

插件管理为运营人员和团队管理员提供插件市场浏览、插件上传、插件授权、我的插件、团队插件和环境分配能力，让用户在浏览器环境创建或编辑前统一维护可用扩展。

## 3. 功能范围与优先级

| 优先级 | 功能 |
| --- | --- |
| P0 | 插件市场、我的插件、团队插件三类视图 |
| P0 | 搜索、内核筛选、功能分类、电商分类、来源筛选 |
| P0 | 添加插件、插件授权协议确认、分配环境 |
| P0 | 上传插件 URL 或安装包、格式与网络限制说明 |
| P1 | 创建我的分组、创建团队分组 |
| P1 | 开启全局、团队可见、删除确认 |

不在本期范围：真实访问 Chrome/Firefox 商店、上传真实插件包、审核插件、安装到真实环境、下载 CRX/XPI 文件、修改浏览器真实扩展目录。

## 4. 关键事实与边界

- 插件市场包含内核筛选：全部内核、谷歌、火狐。
- 功能分类包含热门推荐、选品专区、运营工具、店铺运营、推广营销、达人邀约、其他工具。
- 电商分类包含亚马逊、速卖通、eBay、Etsy、Shopee、Shopify、Lazada、Yahoo。
- 我的插件和团队插件支持是否开启全局、是否分配环境、团队是否可见、来源和内核筛选。
- 上传插件支持 Chrome/Firefox 插件 URL，也支持安装包；Chrome 为 crx/zip，Firefox 为 xpi，限制 50M。
- URL 上传类型需使用非中国大陆网络；应用由第三方提供。
- 插件授权需勾选用户授权协议、隐私协议，可选择收录入团队插件。

## 5. 页面结构

页面复用云登管理中心 App Shell，侧栏高亮插件管理。业务区包含：

1. 插件市场：分类筛选、插件卡片、添加/分配环境。
2. 我的插件：已添加插件、分组、全局开关、环境分配、删除。
3. 团队插件：团队可见插件、团队分组、环境分配。

共用弹窗：上传插件、授权确认、分配环境、创建分组、开启全局确认、删除确认。

#### 5.1.3 页面模块布局

| 模块 | 位置与层级 | 内部组成 | 尺寸与间距 | 滚动、固定与联动 |

#### 5.1.4 响应式与溢出规则

- ≥1280px 展示完整页签、筛选项和多列卡片；插件卡片标题最多两行，超出省略。
- 768-1279px 筛选项自动换行，卡片改为 2 列；表格保持横向滚动。
- ＜768px 左侧导航改为抽屉；筛选区折叠为“筛选”入口；插件卡片单列展示，行操作收纳到更多菜单。

## 6. 插件市场

- 支持内核、功能分类、电商分类、关键词搜索。
- 插件字段：名称、副标题、简介、下载量、操作。
- 添加插件前必须展示授权弹窗并勾选协议。
- 部分已添加插件显示“分配环境”，未添加显示“添加”。
- “查看更多”加载更多市场插件，原型只追加 mock 数据。

## 7. 我的插件与团队插件

- 支持搜索扩展程序。
- 支持筛选：是否开启全局、是否分配环境、全部内核、团队是否可见、全部来源。
- 插件字段：名称、副标题、来源、添加人、简介、版本时间、分组、操作。
- 操作：分配环境、开启全局、团队可见、删除。
- 开启全局提示：设置后，我可操作的环境将均加载该插件。
- 删除插件需二次确认。

## 8. 上传插件

- URL 上传字段：Chrome/Firefox 插件 URL，必填。
- 文件上传说明：Chrome 支持 crx、zip，Firefox 支持 xpi，限制 50M。
- 如果同时上传谷歌和火狐插件，应将 crx 和 xpi 置于同一文件夹打包成 zip。
- 原型仅校验输入，不上传文件或访问第三方商店。

## 9. 分组管理

- 创建我的分组或团队分组。
- 字段：名称必填、备注最多 30 字、插件选择。
- 支持未选择/已选择切换，支持搜索扩展程序和倒序排序。
- 保存后在原型中更新分组数据。

## 10. 分配环境

- 支持环境分组树：工作台、默认分组、转移分组、007。
- 支持环境列表、全选、已选择环境、清空已选、跳过分配和确定分配。
- 确定后只更新原型内插件的已分配环境数。

## 11. 状态与异常

| 场景 | 响应 |
| --- | --- |
| 未勾选授权协议 | 阻止添加插件并提示先同意协议 |
| URL 为空或格式不正确 | 字段标红并阻止上传 |
| 未选择分组名称 | 字段标红并阻止创建 |
| 删除插件 | 二次确认后移出当前 mock 列表 |
| 全局开启 | 二次确认并提示影响可操作环境 |
| 无筛选结果 | 展示空状态 |

## 12. 接口建议

- `GET /plugins/market`
- `POST /plugins/{id}/add`
- `POST /plugins/upload`
- `GET /plugins/mine`
- `GET /plugins/team`
- `PATCH /plugins/{id}`
- `DELETE /plugins/{id}`
- `POST /plugins/{id}/assign-envs`
- `GET /plugin-groups`
- `POST /plugin-groups`

## 13. 安全、权限与审计

- 插件上传、删除、团队可见、全局开启和环境分配均需权限控制与审计。
- 第三方插件需展示来源、授权协议和隐私协议。
- 原型不得执行真实插件安装、上传、下载或环境注入。

## 15. 验收标准

1. 插件市场、我的插件、团队插件可切换。
2. 插件市场支持内核、分类与关键词筛选。
3. 我的插件和团队插件支持全局、分配、来源和内核筛选。
4. 上传插件弹窗包含 URL、安装包格式、50M 限制和网络说明。
5. 添加插件必须经过授权协议确认。
6. 分配环境弹窗可选择环境并更新演示状态。
7. 创建分组可校验名称并选择插件。
8. 开启全局和删除插件均有二次确认。
9. 业务标注从 1 连续编号、默认隐藏，弹窗打开时仅展示弹窗范围标注。
