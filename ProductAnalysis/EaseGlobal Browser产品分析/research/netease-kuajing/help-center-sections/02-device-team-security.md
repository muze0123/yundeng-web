### 1. 如何添加自有设备

- **节点/图片**：`862733690163171356`；11 张。
- **功能对象与入口**：把外部代理作为自有设备接入；入口为【设备管理】-【添加自有设备】，支持单个添加和下拉菜单【批量操作】。该能力被正文称为“限时免费”，并提供专线加速，但未给截止时间或收费恢复规则。
- **字段与前置**：基本设置含设备名称、网络类型；代理信息含代理类型（HTTP/HTTPS/SOCKS5/SSH/SSL）、设备地址（IP/域名）、端口号、代理账号、代理密码。前 3 类连接信息必填，账号/密码可留空用于免密线路；密码默认脱敏并有眼睛图标。正文推荐静态网络，图片同时显示静态/动态单选。
- **按钮与状态**：填写后【网络检测】；成功弹窗显示协议、IP、端口并可【确认添加】，失败可【重新检测】。成功设备进入“可用设备”，状态为“正常”，可【编辑设备】。批量链路为【模板下载】-> 上传表格 -> 校验结果预览 ->【确认提交】；错误数据要求【重新导入】，成功后列表出现新设备并显示“提交成功”。
- **角色/限制/异常**：文章未说明所需角色；网络故障需先用百度/Bing区分设备线路与本机/店铺环境问题，再检查 VPN/其他代理、重启店铺或联系 IP 服务商。模板截图补充列为设备名称、网络类型、代理类型、设备地址、端口号、代理账号、代理密码，并列出文件行数、协议枚举和必填规则；正文没有批量上限、重复行和部分成功的正式口径。

### 6. 如何购买设备

- **节点/图片**：`819630919475085325`；13 张。
- **入口**：①首页【购买设备】或热门设备【立即选择】；②【设备管理】右上【购买设备】。
- **选择与字段**：按主体与店铺场景选择地区、服务商和设备；购买时长为 1/3/6/12/24 个月，数量、优惠券、协议、自动续费和支付方式共同决定订单。订单金额为单价×购买时长，不同服务商和地区价格不同，时长券会延长实际时长。
- **状态流转**：选择设备 ->【立即购买】-> 费用管理选择支付方式/自动续费 ->【立即支付】-> 余额支付确认弹窗【确认】-> 通常 5–15 分钟发货 -> 设备管理可见 -> 添加/编辑店铺时【绑定设备】-> 勾选设备【确定】。
- **角色/限制/异常**：文章未给角色；设备类型有最大购买数量，更多需求联系客户服务；库存不足可预约；超时未到货联系在线客服。使用须遵守中国大陆法律法规。

### 7. 如何更换设备IP

- **节点/图片**：`830410260946063421`；10 张。
- **入口与权限**：【设备管理】-可用设备-目标设备更多-【更换设备】；成员账号另需角色权限“设备管理-更换设备”。无剩余更换次数时入口不可点。
- **处理方式**：①自动更新为新设备，旧设备绑定的店铺自动换绑；②自动解绑，旧设备所有店铺解绑，之后手工重新绑定。选择时只能在“同价格+同供应商”范围内挑选，部分设备不支持更换。
- **状态流转**：选择旧设备处理方式 ->【下一步】-> 选择可更换套餐 -> 查看更换前/后到期时间 ->【确认更换】。阿里云、网易自建及运营商设备到期时间不变；静态住宅 IP 会按已使用天数折算，折算后不足 1 个月则阻止下一步。
- **限制/异常**：库存不足需稍后重试；更换次数按购买/续费页面当时策略赠送、可能调整、设备间不可共享。图片显示剩余次数、禁用的下一步、规则展开区和“当前设备剩余时长无法支持更换”提示。
- **图片补充**：截图还显示更换列表的地域/地区、套餐、预计到期时间，以及权限配置中的【更换设备】勾选项；10 张均可辨识。

## 五、跨文章端到端逻辑

1. **设备供给链**：平台购买设备或导入自有代理 -> 网络检测/支付交付 -> 设备进入“可用” -> 店铺绑定 -> 专属窗口访问。平台设备受地区、服务商、库存、购买时长和换 IP 规则约束；自有设备由用户自行保障代理可达性。
2. **设备生命周期**：购买/导入 -> 正常 -> 可能换 IP/续费 -> 到期前 7 日预警 -> 到期解绑并不可找回。换 IP 的“自动替换绑定”或“自动解绑”会直接影响店铺可访问性，因此必须把设备操作日志与店铺绑定状态一起审计。
3. **团队组织链**：创建团队 -> 部门树 -> 角色模板/自定义权限 -> 添加成员 -> 分配部门和角色 -> 授权店铺 -> 配置登录限制 -> 日志/监控审计 -> 暂停、恢复或删除。成员的最终能力是角色权限、层级范围、部门数据范围、店铺授权、登录控制和访问策略的交集。
4. **登录风控链**：管理员为成员设终端/地区/时间规则 -> 不命中则直接登录 -> 命中后成员提交原因 -> 更高角色审核 -> 新终端/地区可一次放行，时间超限需改规则 -> 登录与审核行为留痕。
5. **访问防泄密链**：通用策略默认禁止密码明文、F12 和打印 -> 水印标识操作者 -> 访问策略限制整页或页面元素 -> 访问日志记录未被整页阻断的行为 -> 店铺监控录屏 -> 30 天内按成员、店铺、终端、URL 和操作类型回放。
6. **审计对象互补**：登录日志回答“谁从哪里何时登录”，操作日志回答“谁对哪家店铺/设备做了什么”，访问日志回答“策略范围内访问了什么”，监控录像回答“屏幕上实际发生了什么”。四者不是同一数据源，保留期也只有监控明确为 30 天。

## 六、矛盾、缺口与版本风险

### 已确认的文档口径冲突

1. **暂停成员是否保留店铺授权**：新版「如何禁用团队成员」明确说店铺绑定关系保留、恢复后可继续用；「成员管理常见问题」明确说暂停会自动取消原授权店铺。两者不可同时成立，且会影响离职管控和恢复成本，需以当前生产实机为准。
2. **谁能看全团队日志**：「如何查看操作日志、登录日志」称 Boss、团队管理员可查看全团队；「角色不同权限说明」把操作日志列为超级管理员专属。需要区分“系统管理员角色”和口语化“管理员”。
3. **谁能配置访问策略**：访问策略正文泛称“团队管理员”，角色矩阵却限定超级管理员；页面元素文章也使用泛称管理员。应以角色权限树当前实际可选项为准。

### 图片与正文的版本/范围差异

1. 「平台设备使用方法」唯一图片是明显旧版白色表格界面，其他设备文章是新版浅蓝界面；操作目的相同，但按钮位置不可直接沿用。
2. 两篇“常见问题”的登录申请与访问拦截截图来自旧版，当前新版入口名称为“登录控制/登录申请”“访问策略管理”；业务逻辑相近，导航文案已变化。
3. 设备购买截图显示示例价格、折扣和支付余额，均为截图时点数据，不是固定商业规则；正文只支持公式和购买时长作为稳定口径。
4. 图片揭示而正文未完整定义的状态包括“更换中”“记录中”、可信终端/地区审核页签、监控店铺 `1/1000` 计数、批量导入模板约束。这些可视为界面证据，但在未实机操作前不能扩写为完整后台规则。

### 尚缺正式规则

- 安全管理的角色权限矩阵未包含店铺监控、监控日志、通用策略和水印；“管理员”到底指管理员还是超级管理员不明确。
- 日志保留期仅监控录像明确为最近 30 天；登录日志、操作日志、访问日志的保留期、导出、不可篡改证明方式未说明。
- 自有设备批量导入缺少最大行数、部分成功、重复设备、回滚和敏感代理凭证保护说明。
- 暂停/删除成员、修改角色、调部门对进行中的店铺会话、已颁发验证码、缓存与店铺授权的原子性和生效延迟未说明。
- 访问策略只支持预设模板，网页结构或语言版本变化后元素规则是否自动失效、告警或回退未说明。
