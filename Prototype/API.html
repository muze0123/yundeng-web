概览

INTRODUCTION

API可以通过程序的方式读取和写入环境配置信息、启动/关闭浏览器、查询环境等操作。可以配合 Selenium、Puppeteer 等自动化框架使用。

使用方法

  1. 在环境管理页面中，设置 API 接口状态。
  2. API 地址示例：http://localhost:50213/，默认端口为 50213，实际以设置的端口为准。
  3. 可以使用脚本或 HTTP 请求工具调用接口。
  4. 参数类型均为字符串，请求体使用 JSON 格式；非必需参数可以省略。

调用频率限制：每个接口每秒最多请求 1 次。建议在客户端实现退避与重试提示。
