## 环境提示（本轮踩坑）
- `python3 -m http.server 8899` 用 `(… &)` / `nohup … & disown` 启动后，**会在两次 Bash 工具调用之间被回收**，下一轮 agent-browser 一定 `ERR_CONNECTION_REFUSED`。
  可行做法：**把启动服务、打开页面、eval 脚本、kill 服务写在同一次 Bash 调用里**（`python3 -m http.server 8899 >/tmp/yd_http.log 2>&1 & SRV=$!` … `kill $SRV`）。
- agent-browser 打开后需 `sleep 3` 再 eval，否则模块 iframe 尚未渲染（返回 `"no module"`）。
- 模块内 `validateInvoice()` 等 IIFE 内函数**不在 window 上**，无法直接调用；改用 UI 驱动（找按钮文案 → `click()` → 派发 `input` 事件 → 观察步骤指示器 `[data-invoice-step-indicator]` 与 `.invoice-field-error`）。
